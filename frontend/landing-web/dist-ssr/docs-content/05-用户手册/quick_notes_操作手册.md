# Quick Notes · 操作手册

> **给谁看**：随手记点东西、过后能搜到的人。
> 全文按界面上实际点的位置写 —— 每一步都说清「点哪里 → 看到什么 → 填什么」。

---

## 一、这个模块解决什么问题

一块**随手可写的便签墙**：临时的电话、待确认的清单、会议要点，先记下来，回头用关键词搜。
每条便签能给一个**颜色**，一眼区分类型（比如黄色=待办、红色=紧急）。

特点就一个字：**快** —— 不用选文件夹、不用建分类，写就完了。

---

## 二、从哪儿进

后台左侧菜单 → **Quick Notes**（📝）。

| 菜单 | 路径 | 谁能进 |
|---|---|---|
| Quick Notes | `/quick_notes` | 有 `quick_notes:read` 权限即可查看 |

> 想**新建 / 编辑 / 删除**，还需要 `quick_notes:write`。
> **看不到菜单 = 没有权限**，找管理员加。

## 三、怎么用

### 新建一条便签

1. 右上角点 **+ 新建**，页面**顶部展开一块编辑区**；
2. 填两样东西：
   - **标题**（必填）—— 顶部的输入框；
   - **内容**（可选）—— 下面的多行文本框；
3. 选 **颜色**：默认 / 黄色 / 绿色 / 蓝色 / 粉色 / 红色（点色块，选中的会有深色边框）；
4. 点 **保存**。编辑区收起，便签以**彩色卡片**的形式出现在下方。

### 修改便签

卡片右上角 **编辑** → 顶部编辑区会**回填**这条便签的标题、内容和颜色 → 改完点 **保存**。

### 换颜色

**编辑** 便签 → 点另一个色块 → **保存**。卡片背景色随之变化。

### 搜索

右上角**搜索框**输入关键词，**按回车**或点 **搜索**。
搜索会同时匹配**标题和内容**。

### 删除

卡片右上角 **删除**，确认后便签消失（软删除 —— 但页面没有回收站入口，误删要联系管理员从后台恢复）。

> ⚠️ **编辑区一次只能开一个**：想改另一条，先点 **保存** 或 **取消** 关掉当前的。

## 四、字段与状态说明

| 字段 | 说明 |
|---|---|
| **标题** | 必填，卡片上以加粗大字显示 |
| **内容** | 可选，卡片上最多显示前几行，超出部分被截断（点编辑看全文） |
| **颜色** | 默认 / 黄色 / 绿色 / 蓝色 / 粉色 / 红色 |
| **更新时间** | 卡片底部的小字，显示最后一次保存的时间 |

**排序规则**：按**更新时间倒序** —— **最近编辑过的排最前面**（不是按创建时间）。

## 五、常见问题

**Q：为什么我能看到别人写的便签？**
当前列表**不区分创建人**，所有有权限的人共享**同一面便签墙**。它适合团队共享信息；如果你要写私人内容，请注意这一点，或找管理员反馈。

**Q：保存时提示「请输入标题」？**
标题不能为空 —— 至少写一个标题才能保存。

**Q：找不到刚写的内容？**
两个常见原因：① 搜索框里还留着旧关键词，清空后再搜；② 列表按**更新时间**排序，刚保存过的就在最前面。

**Q：内容支持排版吗？**
内容是**纯文本**，支持换行，不支持加粗、表格、图片这类富文本。

**Q：便签删了能恢复吗？**
删除只是打标记，数据还在库里；但页面没有回收站入口，需要联系管理员从后台恢复。

**Q：看得到菜单但按钮点了报错？**
缺少 `quick_notes:write` 权限，找管理员加。
