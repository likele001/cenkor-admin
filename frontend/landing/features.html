核心功能

后台管理平台全功能一览

应用中心、RBAC 权限、通用内容引擎、用户中心、审计日志，一站配齐

🏪

应用中心

应用通过 manifest 声明内容类型、字段、分类、权限与菜单，安装时自动注册到系统，卸载时自动清理，即插即用。

  • 应用安装/卸载/升级
  • 权限与菜单自动注册
  • 内容字段自动生成
🔐

RBAC 权限

角色、权限规则、数据权限三级控制。后台（auth_users）与前台（portal_users）双用户体系完全隔离。

  • 角色与权限规则
  • 数据权限范围控制
  • 前后台双用户隔离
📝

通用内容引擎

V2 通用 cms_entries + 动态字段定义，后台 UI 即可增删改字段，支持 21+ 字段类型、3+ 级分类树、标签系统。

  • 动态字段增删改
  • 21+ 字段类型
  • 多级分类与标签
👤

用户中心

portal-web 独立 SPA，C 端用户注册、登录、资料管理，与后台用户体系完全隔离。

  • C 端注册登录
  • 个人资料管理
  • 独立用户体系
🛡️

审计日志

后台关键操作完整留痕，平台运营可追溯、可审计，安全合规。

  • 操作日志留痕
  • 可追溯审计
  • 安全合规
🏠

私有化部署

Docker Compose、宝塔静态 dist、裸机 systemd 三种部署模式，可独立运营，不依赖任何官网。

  • Docker Compose
  • 宝塔静态部署
  • 裸机 systemd
