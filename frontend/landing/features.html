核心功能

平台全功能一览

AI CMS + 应用中心 + RBAC 权限 + 工作流审批 + 开放接口，一站配齐

🤖

AI CMS 内容引擎

用中文描述业务直接生成内容类型与字段定义，草案确认后才落库；AI 起草强制人审，多语言一条命令批量翻译，检索接入 rerank 精排并保留出处。

  • 对话式建模（草案 → 落库）
  • AI 起草与批量翻译
  • 语义检索 + 引用可回溯
🏪

应用中心

应用通过 manifest 声明内容类型、字段、分类、权限与菜单，安装时自动注册到系统，卸载时自动清理，即插即用。

  • 应用安装/卸载/升级
  • 权限与菜单自动注册
  • 授权码 OTA 免重启升级
🔐

RBAC 权限

角色、权限规则、数据权限三级控制。后台（auth_users）与前台（portal_users）双用户体系完全隔离，CMS 与 AI 能力还做了细分权限。

  • 角色与权限规则
  • 数据权限范围控制
  • 审核独立于编辑
📝

动态建模与多站点

V2 通用 cms_entries + 动态字段定义，后台 UI 即可增删改字段，支持 21+ 字段类型、多级分类树、标签系统与多站点站群。

  • 动态字段增删改
  • 21+ 字段类型
  • 多站点会话级隔离
🔀

工作流审批

可视化流程编排，我的待办 / 我发起的 / 我的已办 / 抄送我的 / 单据管理齐全；AI 工作流按拓扑序执行，画环当场拦住。

  • 可视化流程编排
  • 待办已办抄送
  • AI 工作流引擎
📡

发布与效果统计

官网、Webhook、微信公众号草稿箱、导出四个渠道分发；内容埋点一行脚本接入，停留时长与跳出判定按会话归并后统计。

  • 多渠道分发
  • 零改造内容埋点
  • 效果分析看板
🔌

开放接口

REST 内容引擎、GraphQL 只读查询、MCP Server 三种协议并存，共享同一套权限与检索底座，不做三份数据。

  • REST 内容引擎
  • GraphQL（strawberry）
  • MCP HTTP / stdio
🚀

在线升级

核心平台主动查询最新版本并在工作台提示，upgrade.sh 完成备份→覆盖→迁移→重启→健康检查；应用侧走授权码 OTA。

  • 版本检查与提示
  • 升级脚本自动迁移
  • 应用免重启 OTA
🏠

私有化部署

Docker Compose、宝塔静态 dist、裸机 systemd 三种部署模式，可独立运营，不依赖任何官网。

  • Docker Compose
  • 宝塔静态部署
  • 裸机 systemd
