# 内容管理（CMS）· 操作手册

> **给谁看**：往官网放内容的人 —— 发新闻、更新产品、传案例图、改首页文案、用 AI 批量出稿。
> 全文按**界面上实际点的位置**写：点哪里 → 页面上做什么 → 系统会发生什么。
> 想改这个应用的代码看《二次开发指南》；想安装 / 升级看《部署方案》；想自己改站点模板看《模板开发指南》。

---

## 一、这个模块解决什么问题

CMS 是官网的**内容中台**：内容在后台录，官网读出来展示。里面有**三条并行**的路子，先分清：

| 路子 | 菜单 | 表单 | 适合 |
|---|---|---|---|
| **固定表单**（开箱即用） | 产品 / 案例 / 新闻 | 字段写死，不能加 | 官网现成的三个板块 |
| **内容引擎**（可自己造） | 内容类型 → 通用内容 | 字段自己加，想加几个加几个 | 新板块，如「解决方案」「招聘岗位」 |
| **AI 内容中心**（批量出稿） | AI 工作台 / 批量生产 / 落地页工坊 | AI 先生成草稿，人再改 | 量大、要 SEO 铺量、要快速做落地页 |

> ⚠️ **最容易搞混的一件事**：「内容类型」里加字段，**只影响「通用内容」菜单**，**不会**改变「产品 / 案例 / 新闻」的页面。那是两套数据、互不干扰。

内容引擎四层结构：**内容类型**（一类内容）→ **字段**（这类内容填什么）→ **分类 / 标签**（归类和打标）→ **内容条目**（真正写的一条条内容）。

完整链路：**建内容类型 → 加字段 → 建分类标签 → 录内容 → 发布 → 官网读取**。

AI 那条路的链路不一样：**配 AI 能力 → 给素材 → AI 出草稿 → 人工审改 → 发布 →（可选）分发到公众号/其他渠道**。

## 二、从哪儿进

后台左侧菜单里有**两块**跟内容相关：**内容管理** 和 **AI 内容中心**。它们是两个顶级菜单，不是父子关系。

## 三、二十分钟跑通主线

### 路线 A：只发一条新闻（最快）

进 **📰 新闻** → **新建**，填：**标题**（必填，列表显示的就是它）、**Slug**（必填，网址里的英文短名，同类内不重复）、**摘要**（列表和分享卡片的短描述）、**封面图**（图片地址，先去媒体库传图拿链接）、**内容**（Markdown 正文）、**状态**、**SEO 三件套**（Meta 标题 / 描述 / 关键词，留空用标题兜底）。

保存 → 状态改成 **已发布** → 官网立刻能读到。

### 路线 B：自己造一个内容类型（内容引擎）

**第 1 步 · 建内容类型。** 进 **🗂 内容类型** → **新建内容类型**，弹窗里填：

- **Key** —— 英文标识如 `solution`，⚠️ **创建后不能改**，改只能删了重建；
- **名称 / 描述 / 图标** —— 名称如「解决方案」，图标填个 emoji；

**第 2 步 · 加字段。** 内容类型列表里点进 **字段管理**，加你要的字段（文本、长文本、数字、日期、图片、下拉、多选等）。字段的 **Key** 同样建完不能改。

**第 3 步 · 建分类、标签（可选）。** 进 **🏷 分类管理** / **🔖 标签管理**，注意它们**按内容类型分开**——建之前先选好是给哪个内容类型建的。

**第 4 步 · 录内容。** 进 **✍️ 通用内容** → 顶部下拉选这个内容类型 → **新建** → 填标题、Slug、分类、标签、各字段、状态。

**第 5 步 · 发布。** 两种走法：

```
草稿 ──提交审核──> 待审核 ──通过──> 已发布
  ↑                   │
  └────────驳回────────┘        （已通过可再次提交审核）
```

想直接上线：**状态** 选 **发布** 保存即可。想走审核：存草稿 → **提交审核** → 变 **待审核** → 有权限的人点 **通过并发布**（或 **驳回**，退回 **草稿**）。还没发布想先看效果：点 **🖥 暂存预览（未发布）** 打开带令牌的预览链接，**发布后自动失效**。

**第 6 步 · 官网怎么读到。** 官网通过公开接口读内容：只有**已发布**的会出现在公开列表；支持按**内容类型 / 分类 / 标签 / 关键词**筛，也支持多语言。真实渲染效果去 **🖥 模板预览** 对着调。

### 路线 C：让 AI 写一篇（新）

1. **先配能力**：**AI 内容中心 → AI 能力配置**，绑定模型服务商与密钥。没配的话工作台会提示「去 AI 设置绑定服务商与密钥 →」。
2. **进工作台**：**AI 内容中心 → AI 内容工作台**，选择内容类型；没有合适类型就先点「用 AI 建模向导创建一个」。
3. **给素材**：在「素材 / 大纲」里贴资料、要点、竞品链接摘要。给得越具体，稿子越能直接用。模型开始出字大约 **5~15 秒**。
4. **人工审改**：AI 出的是**草稿**，会直接进草稿箱，**不会自动发布**。改完按路线 B 的第 5 步发布。

## 四、日常操作速查

**通用内容** —— 顶部下拉切内容类型（列表、分类、标签跟着换一套）；支持搜索、按分类筛、按状态筛，列表底部显示「共 N 条」；勾选多条可**批量**发布 / 转草稿 / 归档 / 删除；点标题进编辑页。

**产品 / 案例 / 新闻** —— 三张固定表单，字段各自不同：

| 菜单 | 主要字段 |
|---|---|
| 📦 产品 | 名称、中文名、一句话卖点、**产品线**（enterprise / ai / manufacturing）、技术栈、描述、特性列表、是否旗舰、是否开源、GitHub / Demo / 官网地址、许可证、排序、状态、SEO 三项 |
| 📋 案例 | 行业、名称、描述、标签、跳转链接、排序、状态、SEO 三项 |
| 📰 新闻 | 标题、Slug、摘要、封面图、Markdown 正文、状态、SEO 三项 |

三个列表页的能力**不完全一样**，别按一个套路找按钮：

| 菜单 | 列表页能做什么 |
|---|---|
| 📦 产品 | 搜索、**状态页签**（全部 / 已发布 / 草稿 / 已归档）、勾「包含已删除」看回收站、**批量删除 / 批量改状态**、导出 CSV、单条删除 |
| 📰 新闻 | 搜索、导出 CSV、新建、编辑、单条删除（表格里显示 标题 / Slug / 状态 / 阅读数） |
| 📋 案例 | 卡片式展示（行业 + 标签 + 名称 + 描述），搜索、导出 CSV、新建、编辑、有外链的点「查看」跳过去 |

**内容搜索** —— 顶栏搜索框或 **🔍 内容搜索** 菜单进入。跨内容类型全局搜，直接定位到条目，省得逐个菜单翻。

**语言管理** —— 维护语种清单：**代码**（`zh-CN`、`en-US`，必须按这个格式写）、**名称**、**旗帜 emoji**、**是否默认语言**（只能有一个默认）、**是否启用**、排序。这里只是「清单」，内容类型还要单独勾「多语言」才会出现翻译页签。

**媒体库（传图的唯一正确姿势）** —— 进 **🖼 媒体库**：

1. **上传**：点中间虚线区域（或把文件**拖进去**），支持一次选多个；
2. 系统自动命名成 `年/月/随机串.后缀`，图片自动读出**宽 × 高**显示在卡片右下角；
3. 上方三个统计：**总文件数 / 图片 / 总大小**；可筛 **全部 / 图片 / 文档**，也可搜索；
4. **点任意卡片** → 右下角弹出**详情侧栏**：文件名、类型、大小、尺寸、上传时间，下面输入框里就是**可直接用的图片地址**；
5. 三个动作：**复制 URL**（拷**永久地址**，粘到封面、截图等任何地方）、**打开**（新窗口预览原图）、**删除**（⚠️ 会**同时删掉对象存储里的文件**，不可恢复）。

> 媒体文件实际存在**当前激活的云存储**里（在哪配见《云存储 · 操作手册》）。云存储没配好，上传会报错。

**站点配置** —— 一张「键 → 值」表，改完点该行的 **保存**。默认预置：`brand.name` / `brand.name_en`（品牌中英文名）、`brand.domain`（主域名）、`brand.tagline`（一句话）、`brand.description`（品牌介绍）、`contact.email` / `contact.bd_email` / `contact.support_email`（联系 / 商务 / 支持邮箱）。值可以是纯文本、数字、`true`/`false`，或一段 JSON（以 `{` 或 `[` 开头就按 JSON 解析）。

## 五、AI 内容中心怎么用

17 个菜单看着多，实际只有四件事：**生产 → 质检 → 分发 → 配置**。日常真正天天用的是前三个菜单。

### 5.1 生产：AI 内容工作台（主力）

给素材 → 出草稿。四个能力都在这一页：

| 能力 | 怎么用 | 什么时候用 |
|---|---|---|
| **起草** | 选内容类型 → 贴素材/大纲 → 等 5~15 秒出稿 | 从零写一篇 |
| **翻译** | 已有条目 → 选目标语种 → 翻 | 内容要出海 |
| **SEO** | 基于正文生成 Meta 标题 / 描述 / 关键词 | 补 SEO 三件套，别手抠 |
| **相似推荐** | 出稿时顺带找站内相似内容 | 避免重复选题、顺手做内链 |

### 5.2 生产：批量生产

「一次起草 N 篇，全部落成草稿」。

- **批次名称**（选填）：方便事后在批次列表里找回来；
- **并发**：默认 1（稳，推荐）；4 是「快，但容易被服务商限流」；
- **上限 200 篇**，超过会被直接拒绝。

> ⚠️ 批量产出全部是**草稿**，不会自己发出去。200 篇草稿一起等着你审，请安排好人力。

### 5.3 生产：落地页工坊

「一句话生成可投放的落地页 / 官网子站」。

1. **① 一句话说清楚要什么** —— 写得具体：卖给谁、解决什么问题、目标是留资还是约演示；
2. **② 检查内容再保存** —— AI 会给出 SEO 标题等，逐项过一遍再存；
3. **③ 预览** —— 与线上同一套渲染，所见即所得；
4. 形态二选一：**单页落地页** 或 **官网子站（4 页）**。页面上的表单**直接进 CRM 线索池**。

> 落地页的地址（URL）归 **URL 规则** 管，不在工坊里配。见第六节。

### 5.4 生产：知识库（决定 AI 会不会瞎编）

「产品手册 · FAQ · 历史方案 —— 让 AI 有据可依」。

- 上传 PDF / 文档后，系统抽取纯文本并切成「可检索分片」；
- **扫描件 PDF 抽不出文字**，会直接报错说明原因 —— 请先做 OCR 再传；
- 页面底部有一个「问一句，看会召回哪几段」的自测框 —— **知识库到底有没有用，这里最直接**，传完务必试一句。

### 5.5 质检

| 菜单 | 怎么读结果 |
|---|---|
| **内容体检** | 给站点打健康分，并按「命中篇数 × 单条扣分」排出**先改这几件**。待处理条目按分数升序，最该修的在前 |
| **问答自测** | 模拟访客提问，看系统答不答得上。召回为空或「未调用模型（检索降级）」= 内容不够或知识库没建好 |
| **选题缺口** | 列出「该写但没写」的话题，还能看到访客可能接着问什么 |
| **AI 质量台** | 抽查 AI 稿的质量 |
| **内容效果** | 内容的数据表现 |

### 5.6 分发与编排

- **分发渠道**：把内容发到站外（如公众号）。页面有「执行待处理任务」按钮和「最近发布任务」列表，**结果 / 原因**列会写清成功还是为什么失败。
- **工作流编排**：把「选题 → 起草 → 审核 → 发布」串成流水线，省掉手工一步步点。

### 5.7 配置

| 菜单 | 说明 |
|---|---|
| **AI 能力配置** | **必先配**：模型服务商、密钥、默认模型。没配之前所有 AI 页面都不可用 |
| **提示词管理** | 出稿用的提示词模板，有版本管理，改坏了能回退 |
| **AI 用量** | 谁用了多少 token / 花了多少钱，按人、按天看 |
| **AI 记忆** | 让 AI 长期记住品牌口径、写作禁忌、禁用词 |

## 六、进阶

### 6.1 模板工作台（🖥 模板预览）

> ⚠️ **重要更正**：早期文档写的是「Liquid 模板」，**现在用的是 Jinja2**。两者语法不同，老写法直接搬过来会报错。

进 **🖥 模板预览**（实际是**模板工作台**）：

- 左侧是**文件树**（`layout.html` / `detail.html` / `page.html` / `list.html` / `404.html` / `partials/` / `macros/` / `assets/`）；
- 中间写模板，右侧**预览**；
- 顶部有 **标签速查** 按钮 —— ⭐ **写模板时先点它**。面板里列出全部能用的东西，分三页：
  - **数据 API**：16 个取数据的函数（条目列表、分类、菜单、分页、搜索……），按内容/结构/站点/其他分组；
  - **过滤器**：16 个加工函数（日期、Markdown、摘要、货币、缩略图……）；
  - **变量**：`page` / `item` / `items` / `site` 这些已经塞好的变量，直接写名字就能用。
  
  点任意一条会把**可直接用的代码**插到光标处（列表类的会自动带 `for` 循环骨架，光标落在循环体里），
  上方搜索框按用途搜最快 —— 搜「分页」「日期」「图片」都行。
- 顶部还有 **使用说明** 按钮 —— 五个最常见的坑都在里面，**先点它再动手**；
- 改完先 **保存**，再 **设为生效** —— ⚠️ **保存 ≠ 生效**，这是最容易卡住的一步。

三条必须知道的事实：

1. **首页 `/` 不归模板管。** 首页是 nginx 直接返回的静态 `index.html`，改模板永远改不动它。
2. **预览框里禁用脚本**（iframe 沙箱）。主题 JS 改动要**保存并生效后**，在线上才看得到效果。
3. **「标签」不是短代码。** 没有 `{dede:xxx}` / `[gallery]` 这类写法，数据一律用函数取：
   `{% for r in content_list('article', limit=6) %}`。名字不用背，标签速查面板里点。
4. 完整写法、从零做一个主题的实战教程见《模板开发指南》（`docs/template-guide.md`）。
5. **不想进网页编辑器？** 也可以直接在服务器磁盘目录 `var/themes/<主题名>/` 里建模板文件，
   磁盘优先、约 2 秒生效，工作台文件树会带绿色「盘」徽标 —— 详见指南「第十·补、磁盘主题目录」。

### 6.2 URL 规则（🔗 决定官网地址长什么样）

全站地址是否带 `.html`、详情页前缀是 `/article/` 还是 `/news/`，都在这里配。**四层，就近优先**：

| 在哪配 | 管什么 | 例子 |
|---|---|---|
| 内容编辑页 → **自定义地址** | 单条内容自己 | 这一篇走 `/promo/xxx.html` |
| **栏目（分类）管理** → 栏目级规则 | 这个栏目**自己的页面地址** | `/category/ai/` → `/topic/ai/` |
| **标签管理** → 标签页规则 | 这个标签页的地址 | 标签页从 `/tag/mes/` 改成 `/topic/mes/` |
| **URL 规则** → 全站默认 | 其余所有 | 全站详情页默认 `/article/{slug}.html` |

> ⚠️ **栏目级规则只管这个栏目自己的页面，不改它底下内容的详情页地址。** 这是有意设计的：不然后台一改栏目，底下几百篇文章的链接全变，SEO 直接崩。

改完之后：**新地址可直接访问，老地址自动 301 跳新地址**，不会断链。页面上的 **canonical** 也会跟着收敛到新地址。

保存规则需要 `cms:site:write` 权限。只读角色进去只能看和预览，**保存按钮不显示**（规则是全站生效的，误操作代价太大）。

### 6.3 页面构建（🧩 可视化拖拽）

**内容管理 → 页面构建**。左侧是区块库（图片、自定义 HTML、文本等），**拖到画布**或**点击添加**；在画布中点选某个区块，右侧改它的属性（图片地址 src、替代文本 alt 等）。适合做「关于我们」「活动专题」这类结构简单的页面。复杂排版仍建议走模板。

### 6.4 多语言

① 先到 **🌐 语言管理** 维护语种清单；② 内容类型上勾选 **多语言**；③ 录内容时顶部出现语言页签（**主语言** + 各语种），逐个填、各自保存。

### 6.5 版本与暂存预览

每次保存自动生成版本快照，点 **查看** 看当时内容、点 **回滚** 退回该版本（回滚前会先把当前内容再存一份快照，丢不了）。暂存预览给未发布内容生成临时链接，发给同事确认，内容一发布链接即失效。

### 6.6 批量导入

通用内容支持批量导入，适合一次性搬几十条内容进来。

## 八、权限对照表

权限点和菜单一一对应，「读」管看、「写」管改：

| 权限 | 能做什么 |
|---|---|
| `cms:content_types:read` / `write` | 看 / 建改删 **内容类型** |
| `cms:field_definitions:read` / `write` | 看 / 建改删 **字段** |
| `cms:categories:read` / `write` | 看 / 维护 **分类** |
| `cms:tags:read` / `write` | 看 / 维护 **标签** |
| `cms:entries:read` / `write` | 看 / 录改删 **通用内容**、**内容搜索**、**语言管理** |
| `cms:product:read` / `write` | 看 / 维护 **产品** |
| `cms:case:read` / `write` | 看 / 维护 **案例** |
| `cms:news:read` / `write` | 看 / 维护 **新闻** |
| `cms:site:read` / `write` | 看 / 改 **站点配置**、**模板工作台**；**URL 规则的保存另需 `write`** |
| `media:upload` | **媒体库**（上传、复制链接、删除） |
| `settings:read` | **页面构建** |
| `cms:entry:review` | **审核通过 / 驳回**（通用内容的发布工作流） |
| `cms:ai:read` / `cms:ai:manage` | 看 / 管理 **AI 内容中心**各页（批量生产、配置类要 `manage`） |

> ⚠️ **`cms:entry:review` 不在这个应用的权限声明清单里** —— 装应用时不会自动出现，需要管理员在角色权限里手动加上，否则「待审核」的内容没人能批。
>
> ⚠️ **`cms:ai:manage` 同理**，批量生产等写操作要单独加。

**建议分法**：

- **内容编辑** = `cms:entries:read/write` + `cms:news:read/write` + `cms:product:read/write` + `cms:case:read/write` + `cms:categories:read` + `cms:tags:read` + `media:upload` + `cms:ai:read`
- **内容负责人** = 上面全部 + `cms:entry:review` + `cms:ai:manage`
- **站点管理员** = 全部 `cms:*` + `settings:read`

## 九、常见问题

**Q：在「内容类型」里加了字段，为什么「产品」页面没有？** 那是两套东西。「产品 / 案例 / 新闻」是固定表单，「内容类型 + 字段」只作用于「通用内容」。

**Q：新建内容类型时 Key 填错了能改吗？** 不能，编辑里 Key 是灰的。只能删掉重建。

**Q：录内容时找不到我要的分类 / 标签？** 三查：① 内容类型有没有勾「支持分类 / 支持标签」；② 分类 / 标签是不是建在**同一个内容类型**下（它们按内容类型分开）；③ 列表顶部选的内容类型对不对。

**Q：内容建好了，官网怎么没变？** 状态必须是 **已发布**。草稿、待审核、已归档都不会出现在公开列表里。另外前台可能有缓存，稍等或清缓存。

**Q：改了模板，预览没变 / 线上没变？** 三查：① 是不是只**保存**了没点**设为生效**（最常见）；② 改的是不是**首页**（首页是 nginx 静态文件，不归模板管）；③ 改的是不是 JS（预览框禁脚本，线上才生效）。

**Q：改了网址规则，老链接打不开了？** 正常情况下老地址会 301 跳到新地址。如果 404，检查规则里是不是写死了详情页前缀，以及前台缓存是否还指着旧地址。

**Q：AI 页面提示「去 AI 设置绑定服务商与密钥」？** 还没做第五节 5.7 的配置。先在 **AI 能力配置** 里绑好服务商和密钥。

**Q：AI 写的内容直接发出去了吗？** 没有。AI 产出**全部进草稿箱**，必须人工审改后手动发布。

**Q：AI 写的东西跟我们的产品对不上 / 像在瞎编？** 知识库是空的或没传对。去 **知识库** 传产品手册 / FAQ，传完用页面底部的自测框问一句，确认能召回再让 AI 写。

**Q：知识库传 PDF 报错？** 扫描件 PDF 抽不出文字。先 OCR 成可复制文本的 PDF 或直接传文字版。

**Q：批量生产失败 / 被限流？** 并发调回 1。4 只是「快」，代价就是容易撞服务商限流。

**Q：「通过并发布」点了没反应 / 报错？** 缺 `cms:entry:review` 权限 —— 这个权限码默认不在应用的权限清单里，要管理员手动加。

**Q：上传图片失败？** 先看「云存储」应用配好了没 —— CMS 的媒体文件存在当前激活的云存储里。见《云存储 · 操作手册》。

**Q：删了图片，为什么页面上图裂了？** 媒体库的删除是**连对象存储里的文件一起删**。封面图这类被引用的图，先换新图再删旧图。

**Q：想改字段的标识（Key）会怎样？** 老内容里这个字段的值会读不出来（前台渲染为空）。已投入使用的字段只改**显示名**，不动标识。

**Q：批量操作能撤吗？** 不能，批量删除和批量改状态都立即生效，操作前确认勾的是你要的那几条。

## 附：状态速查

| 状态 | 含义 |
|---|---|
| 草稿 | 刚建 / 被驳回 / AI 刚产出，只有后台能看 |
| 待审核 | 已提交，等审核人处理 |
| 已通过 | 审核通过但还未对外发布 |
| 已发布 | 官网可读（终态） |
| 已归档 | 下线存档，官网不显示 |

**产品线取值**：`enterprise`（企业级）、`ai`（AI）、`manufacturing`（制造）。
