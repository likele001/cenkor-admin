技术优势

为什么选择辰科Cenkor Admin

现代技术栈 + 应用中心生态 + 灵活部署，企业级后台管理平台首选

🏪

应用中心生态

应用 manifest 声明内容/字段/权限/菜单，安装时自动注册，卸载自动清理，业务模块即插即用。

📝

通用内容引擎

动态字段定义 + 21+ 字段类型 + 多级分类标签，后台 UI 即可扩字段，无需改代码。

⚡

现代技术栈

FastAPI 异步高性能 + Vue3 + SQLAlchemy 2，PostgreSQL/Redis/MinIO 标准中间件。

🔐

安全可控

JWT 前后台双体系鉴权 + RBAC 权限 + 审计日志，平台安全可追溯。

🏠

灵活部署

Docker Compose / 宝塔静态 dist / 裸机 systemd 三种模式，可独立运营不依赖官网。

🔗

开放 API

公开只读 API（/api/v1/public/*）供任意前端消费，生态开放可扩展。
