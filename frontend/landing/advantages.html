技术优势

为什么选择辰科Cenkor Admin

现代技术栈 + 应用中心生态 + AI 原生内容层，企业级平台与内容引擎双主线

🤖

AI 原生内容层

对话式建模、AI 起草翻译、语义检索、内容生产线。AI 是可选增强 —— 不配模型时传统能力照常工作。

🏪

应用中心生态

应用 manifest 声明内容/字段/权限/菜单，安装时自动注册，卸载自动清理，业务模块即插即用。

🧩

动态建模与多站点

动态字段定义 + 21+ 字段类型 + 多级分类标签，后台 UI 即可扩字段；多站点站群会话级隔离。

⚡

现代技术栈

FastAPI 异步高性能 + Vue3 + SQLAlchemy 2，PostgreSQL 16 / Redis 7 / MinIO 标准中间件。

🔐

安全可控

JWT 前后台双体系鉴权 + RBAC 三级权限 + 审计日志；AI 密钥只出掩码，读配置与改密钥分权。

🔌

三协议开放

REST / GraphQL / MCP 三种出口共享同一套权限与检索底座，Agent 可直接消费内容。

🚀

在线升级

核心平台发现新版本即在工作台提示，升级脚本自动备份与迁移；可插拔应用授权码 OTA，免重启。

📊

可观测

内容埋点、效果统计、AI 用量三段计费与操作审计，效果与成本都能落到数字上。

🏠

灵活部署

Docker Compose / 宝塔静态 dist / 裸机 systemd 三种模式，可独立运营不依赖官网。
