关于 Cenkor Admin 你可能想知道的

部署方式、开源授权、权限与内容引擎…… 一站式解答

Cenkor Admin 是一款企业级平台（FastAPI + Vue3），内置应用中心、RBAC 权限、工作流审批、AI CMS 内容引擎、用户中心与审计日志。适合需要快速搭建内部管理系统、内容站点与官网，或对既有系统做后台底座的企业与团队。

普通 CMS 是先有模型再填内容；AI CMS 是「说人话建模型」——用中文描述业务需求，直接生成内容类型与字段定义（草案先给你看，确认才落库）。再加 AI 起草、批量翻译、语义检索、内容体检与多渠道再分发，最后以 REST / GraphQL / MCP 三种协议交给任意前端与 Agent 消费。

能，而且是刻意设计的。AI 是可选增强不是运行必需：未配置模型时 AI 端点返回明确的 503 提示，而建模 UI、版本管理、多语言、审核、REST / GraphQL / MCP 只读工具完全不受影响。内网离线环境也能先把内容骨架跑起来。

任何 OpenAI 兼容协议的服务都能接：OpenAI、DeepSeek、通义千问、Moonshot、智谱、本地 vLLM / Ollama 或自建网关，改 base_url 与模型名即可，chat 与 embedding 还能绑不同服务商。数据只发往你自己配置的模型服务，平台不中转、不代建账号。

三道闸口：起草强制 draft 状态必须人审才可发布；知识库把产品手册、FAQ、历史方案变成可检索依据，让模型引用事实而不是编事实；问答检索查不到时明确返回「查不到」，宁可空着也不编。另外还有抽样质检与模型 A/B，好坏有数据可比。

三种：Docker Compose（一条命令拉起全栈）、宝塔静态、裸机 systemd。核心平台有新版本时后台顶部会出现升级横幅，用 upgrade.sh 或拉新镜像完成；可插拔应用在应用中心用授权码 OTA 升级，免重启。

开源。代码托管在 GitHub（AGPL-3.0 协议），可自由下载部署使用；应用中心按需扩展，业务模块即插即用。

每个应用通过 manifest 声明内容类型、字段、分类、权限与菜单，安装时自动注册到系统，卸载时自动清理，无需改代码。当前内置 12 个可插拔应用。

角色、权限规则、数据权限三级控制；后台（运营）与前台（C 端用户）双用户体系完全隔离。CMS 与 AI 能力还做了细分权限：读配置与改密钥是两码事，审核动作也独立于编辑。

PostgreSQL（主库）、Redis（缓存/队列）、MinIO（对象存储）以及 backend / admin-web / portal-web 三端服务，容器化一键编排。
