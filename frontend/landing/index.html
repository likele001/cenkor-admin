关于 Cenkor Admin 你可能想知道的

部署方式、开源授权、权限与内容引擎…… 一站式解答

Cenkor Admin 是一款企业级后台管理平台（FastAPI + Vue3），内置应用中心、RBAC 权限、通用内容引擎（CMS）、用户中心与审计日志。适合需要快速搭建内部管理系统、内容站点，或对既有系统做后台底座的企业与团队。

支持三种：Docker Compose（一条命令拉起全栈）、宝塔静态、裸机 systemd。数据部署在自己服务器，完全私有化、自主可控。

开源。代码托管在 GitHub（AGPL-3.0 协议），可自由下载部署使用；应用中心按需扩展，业务模块即插即用。

每个应用通过 manifest 声明内容类型、字段、分类、权限与菜单，安装时自动注册到系统，卸载时自动清理，无需改代码。

后台即可动态增删字段，支持 21+ 字段类型、多级分类与标签，文章/页面/内容类型统一管理，官网内容也能在系统里维护。

角色、权限规则、数据权限三级控制；后台（运营）与前台（C 端用户）双用户体系完全隔离，各自独立登录与权限。

PostgreSQL（主库）、Redis（缓存/队列）、MinIO（对象存储）以及 backend / admin-web / portal-web 三端服务，容器化一键编排。

可以。Cenkor Admin 可独立部署运营，不依赖任何官网；支持多应用并行，适合作为自己的后台底座持续扩展。
