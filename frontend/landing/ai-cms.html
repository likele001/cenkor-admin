三大支柱

AI 不是加个对话框，是改造内容的整条链路

从「想写什么」到「谁在用」，每一步都有 AI 参与，每一步都留了人审的闸口

01
💬

对话式建模

用中文描述业务，直接生成内容类型与字段定义。草案先给你看，确认了才落库 —— 说错一句话不会把库结构改坏。

  • 自然语言 → 内容类型草案
  • 草案确认后才建表
  • 字段类型 / 校验 / 选项一并生成
02
✍️

AI 起草与翻译

按素材或大纲出草稿，强制 draft 状态必须人审；一条命令把内容批量翻译成多语言，保留原有格式与结构。

  • 素材/大纲 → 条目草稿
  • 强制人工审核后发布
  • 多语言批量翻译
03
🔍

语义检索增强

条目自动向量化，只给真正变了的条目付 embedding 的钱；检索接入 rerank 精排，命中片段连同出处一起进提示词。

  • 增量向量化（内容指纹比对）
  • rerank 精排
  • 引用可回溯的 RAG

出口协议

一套内容，三种交付形态

人用 REST、前端用 GraphQL、Agent 用 MCP —— 复用同一套权限与检索底座，不做三套数据

REST后台 / 自定义前端
GET /api/v1/cms/entries?content_type=news
GET /api/v1/public/cms/entries/{slug}
POST /api/v1/cms/ai/draft-entry

内容引擎 39 个端点 + 公开只读端点，权限按码细分到「读 / 写 / 审核」。

GraphQL现代前端按需取数
POST /api/v1/cms/graphql
{
  contentTypes { key name fields { key type } }
  entries(contentType: "news") { title slug }
}

基于 strawberry，与 REST 并存互不影响，/graphiql 可直接调试。

MCPClaude / Cursor / 自研 Agent
POST /api/v1/cms/mcp      # Streamable HTTP
cms-mcp stdio             # 本地进程

自实现 JSON-RPC 2.0 分发，写权限有独立开关，只读工具默认安全。

MCP 同时支持 Streamable HTTP 与 stdio 两种传输， 自行实现以换取对鉴权、事务、错误码的完全控制 —— 交付物离线可部署，不多一个依赖。

一致性

让 AI 越写越像「这家公司的笔」

记忆层管事实与风格，提示词层管措辞与结构 —— 两者都可在后台改，不用发版

三层记忆体系

站点记忆 · 硬事实

产品参数、公司口径、禁用词。错一条就是事故，因此只能人工写。

站点记忆 · 软风格

语言习惯与结构偏好，由 AI 归纳，随时可纠正。

内容记忆 · 条目级

同一选题的历史写法与结论，避免一个月后自我矛盾。

会话记忆 · 对话级

一次会话内的上下文与已确认取舍，追问不必从头解释。

增长与自动化

落地页能生成，流程能画

营销页与内部审批不该各买一套工具

Landing Studio

落地页工作室

描述目标人群与卖点，生成整页落地页：白名单区块逐块校验，模型自创的区块直接丢弃并如实告知； 表单一并生成且默认挂 CRM 线索池，提交即进线索，转化才有数据可算。

区块白名单校验表单 → CRM 线索页面预览一键发布
Workflow Studio

可视化 AI 工作流

画布上连节点，拓扑序执行，画环当场拦住 —— 不检测就会死循环，而前端只表现为多了一条线。 每个节点独立提交，run 到哪一步、哪步失败，都能回看。

拓扑序 + 环检测逐节点提交运行记录四种终态
可控性

花多少钱、用哪个模型，都看得见

🔐

密钥永不明文出接口

接口只返回掩码，编辑时原样回传掩码即等于不修改；密钥加密落库。

🧪

连通性真实测试

保存不报错 ≠ 能用。每个服务商都能发一次最小请求，把「配了但连不上」暴露在界面上。

🧮

用量三段计费

按输入 / 输出 / 缓存分列统计，配合价格表算出真实成本，超预算一眼看到。

🧬

七类能力分别绑定

chat / embedding / vision / image / rerank / asr / tts 各绑各的模型，chat 与 embedding 可来自不同服务商。

🛡️

AI 权限独立收口

读配置要 cms:ai:read，改密钥要 cms:ai:manage —— 高危动作只给管理员。

🧯

失败可降级

向量检索超时降级关键词，模型不可用降级人工流程，内容平台本身不跟着挂。

🔌AI 是可选增强，不是运行必需

未接入模型时，AI 端点返回明确的 503 提示；而建模 UI、版本、多语言、审核、 REST / GraphQL / MCP 只读工具等传统能力完全不受影响。 内网离线环境也能先把内容骨架跑起来，模型随时再接。
