# 工单管理 · 操作手册

> **给谁看**：提问题 / 提需求的人，和负责处理工单的人。
> 全文按界面上实际点的位置写 —— 每一步都说清「点哪里 → 看到什么 → 填什么」。

---

## 一、这个模块解决什么问题

把「有件事要办」变成一张**可追踪的工单**：记下是什么事、多急、归哪类，然后按状态一步步推进，直到关闭。
谁提的、现在什么状态，列表上一眼看得到 —— 不用再靠聊天记录翻「那件事到底办了没」。

---

## 二、从哪儿进

后台左侧菜单 → **工单管理**（🎫）→ **工单列表**。

| 菜单 | 路径 | 谁能进 |
|---|---|---|
| 工单管理 → 工单列表 | `/tickets` | 有 `tickets:read` 权限即可查看 |

> 想**新建 / 编辑 / 删除**，还需要 `tickets:write`。
> **看不到菜单 = 没有权限**，找管理员加。

## 三、怎么用

### 提交一张工单

1. **工单列表** 右上角点 **新建工单**；
2. 弹窗里填写：

   | 填什么 | 说明 |
   |---|---|
   | **标题** | 必填，用一句话说清是什么事 |
   | **状态** | 默认 **待处理**，新建时一般不用改 |
   | **优先级** | 低 / 普通 / 高 / 紧急 |
   | **分类** | 通用 / 缺陷 / 需求 / 支持 |
   | **描述** | 富文本，写清背景、复现步骤、期望结果 |

3. 点 **保存**。列表新增一行，编号形如 **#12**。

### 受理并推进状态（核心流程）

在列表里点 **编辑**，把 **状态** 改成下一步，再 **保存**：

```
待处理  →  处理中  →  已解决  →  已关闭
 open      in_progress   resolved   closed
```

| 状态 | 含义 | 什么时候改成它 |
|---|---|---|
| **待处理** | 刚提交，还没人接手 | 新建时的默认值 |
| **处理中** | 已经有人在做 | 有人认领 / 开始动手时 |
| **已解决** | 事情办完了 | 处理完时；**系统自动记录解决时间** |
| **已关闭** | 确认收尾，不再跟 | 提单人确认没问题时；**系统自动记录关闭时间** |

> 状态可以**跳着改**（比如直接从「待处理」跳到「已解决」），也可以**改回去**（比如「已解决」后发现没修好，退回「处理中」）。

### 修改优先级 / 分类 / 描述

同样是点 **编辑** → 调整 → **保存**。

### 查找工单

列表上方：

- **搜索框** —— 输入标题关键词；
- **状态** 下拉 —— 全部状态 / 待处理 / 处理中 / 已解决 / 已关闭；
- 点 **搜索**。

### 删除工单

点 **删除** 并确认，工单从列表移除。删除是**软删除**，但页面没有回收站入口 —— 误删要联系管理员从后台恢复。

## 四、字段与状态说明

| 字段 | 可选值 | 说明 |
|---|---|---|
| **编号** | #数字 | 系统自动生成，通知里也用编号指代 |
| **标题** | — | 必填 |
| **分类** | 通用 / 缺陷 / 需求 / 支持 | 带颜色标签 |
| **优先级** | 低 / 普通 / 高 / 紧急 | 紧急显示为红色 |
| **状态** | 待处理 / 处理中 / 已解决 / 已关闭 | 见上方流转 |
| **创建时间** | — | 列表按它倒序排列 |

**时间字段（系统自动填，不用手动）**

| 字段 | 什么时候写入 |
|---|---|
| 解决时间 | 状态改成「已解决」的那一刻 |
| 关闭时间 | 状态改成「已关闭」的那一刻 |

## 五、常见问题

**Q：怎么把工单分给某个人？**
分配处理人、工单评论、评论里 `@某人` 这些能力**系统后台已经具备**（一旦分配，被分配人会收到通知），但**当前页面上还没有对应入口**。目前请先用描述字段写明该找谁，或联系管理员。

**Q：我改了状态，谁会收到通知？**
只要**改状态的人不是工单创建人**，创建人就会在顶栏 **🔔 铃铛** 收到一条「工单状态变更」通知。如果把工单分配给某个人，被分配人也会收到通知。详细规则见《通知 · 操作手册》。

**Q：改状态时提示权限不足？**
需要 `tickets:write` 权限，找管理员加。

**Q：为什么大家看到的是同一份工单列表？**
工单是**团队共享**的 —— 只要有查看权限就能看到全部工单，方便协作跟进。

**Q：工单删了能恢复吗？**
删除只是打标记，数据还在库里；但页面没有回收站入口，需要联系管理员从后台恢复。

**Q：优先级和状态有什么区别？**
**优先级**表示「有多急」，是给信息；**状态**表示「走到哪一步了」，决定流程。两者互不影响。
