# ERP 管理系统 · 操作手册

> **给谁看**：工厂 / 贸易公司的业务人员 —— 业务员、采购、仓管、财务、生产、老板。
> 全文按**界面上实际点的位置**写，每一步都说清「点哪个菜单 → 页面上做什么 → 系统会发生什么」。
> 本手册只讲怎么用；想改代码看《二次开发指南》，想安装升级看《部署方案》。

---

## 一、这个模块解决什么问题

把一家公司的生意从「接单」到「收钱」全程搬到线上：

```
客户 → 商品 → 销售订单 → 采购订单 → 收货入库 → 出货出库 → 财务对账
```

中间还挂着几个「专业角色才用」的模块：

| 你想要 | 用哪个菜单 |
|---|---|
| 客户资料、联系人、跟进记录 | **客户管理** |
| 供应商资料 | **供应商** |
| 商品档案（售价 / 采购价 / 成本价 / 最低库存） | **商品** |
| 接单、报价、出货 | **销售订单** |
| 下采购单、收货入库 | **采购订单** |
| 内部要买东西先走审批 | **采购申请** |
| 仓库、库位、批次、序列号、盘点 | **仓库** / **仓储深度** |
| 两个仓库之间调货、给别人留货 | **调拨预留** |
| 开票、收款、付款、应收应付余额 | **财务** |
| 记账凭证、三大报表 | **总账** |
| 客户欠了多久的钱、催收 | **应收账龄** |
| 外币业务与汇率折算 | **多币种汇率** |
| 设备台账、点检保养维修 | **设备管理** |
| 来料/制程/成品检验、不合格品 | **质量管理** |
| 生产 BOM、工单、领料完工 | **制造** / **制造深化** |
| 每天报工、工序验收 | **生产报工** |
| 算成本、期末结转库存 | **成本核算** / **库存结转** |
| 公司设备等固定资产折旧处置 | **固定资产** |

> 主线只要跑通第一节的 8 步，日常单据就都能处理了。其余模块按需再学。

## 二、从哪儿进

后台左侧菜单 → **ERP 管理**（📊），展开后共 **23 项**。按业务分六组：

### 主数据（4 项）

| 菜单 | 路径 | 干什么 |
|---|---|---|
| 👤 客户管理 | `/erp/customers` | 客户档案、联系人、地址、跟进记录 |
| 🏢 供应商 | `/erp/suppliers` | 供应商档案 |
| 📦 商品 | `/erp/products` | 商品档案（含售价/采购价/成本价/最低库存/税率） |
| 🏷️ 价格折扣 | `/erp/price` | 价目表、价格试算、折扣规则 |

### 销售（1 项）

| 菜单 | 路径 | 干什么 |
|---|---|---|
| 📄 销售订单 | `/erp/sales-orders` | 新建订单 → 确认 → 生成出货单 |

### 采购（2 项）

| 菜单 | 路径 | 干什么 |
|---|---|---|
| 🛒 采购订单 | `/erp/purchase-orders` | 新建采购单 → 确认 → 收货入库 |
| 🎫 采购申请 | `/erp/purchase-requests` | 内部申请 → 提交审批 → 转成采购订单 |

### 库存仓储（5 项）

| 菜单 | 路径 | 干什么 |
|---|---|---|
| 📦 仓库 | `/erp/warehouses` | 仓库资料、库存余额、出入库流水 |
| 📦 仓储深度 | `/erp/warehouse-ext` | 库位、批次、序列号、盘点、安全库存预警 |
| 🔀 调拨预留 | `/erp/transfer` | 仓间调拨单、库存预留 |
| 🧊 库存结转 | `/erp/inventory-ext` | 库存期初余额、月末结转 |
| 🔍 序列批次追溯 | `/erp/trace` | 按序列号/批次号查全生命周期事件 |

### 财务（5 项）

| 菜单 | 路径 | 干什么 |
|---|---|---|
| 💰 财务 | `/erp/finance` | 销售/采购发票、收付款、应收应付 |
| 📓 总账 | `/erp/gl` | 会计科目、记账凭证、账簿、三大报表 |
| 🧾 应收账龄 | `/erp/ar-aging` | 账龄分析、应收明细、催收记录 |
| 💱 多币种汇率 | `/erp/currency` | 币种字典、本位币、汇率维护 |
| 🏠 固定资产 | `/erp/assets` | 资产卡片、折旧计提、处置 |

### 生产与制造（6 项）

| 菜单 | 路径 | 干什么 |
|---|---|---|
| ⚙️ 制造 | `/erp/manufacturing` | BOM、生产工单、领料、完工、质检、MRP可用量 |
| 🛠️ 制造深化 | `/erp/mfg-ext` | 工作中心、工艺路线、排产计划 |
| ✅ 生产报工 | `/erp/report` | 报工登记、工序验收、工单看板 |
| 💰 成本核算 | `/erp/cost` | 成本期间、核算结果、归集明细 |
| 📷 设备管理 | `/erp/equipment` | 设备台账、点检、保养、维修工单 |
| ✅ 质量管理 | `/erp/quality` | 检验单、不合格品处理 |

> **看不到某个菜单 = 没有对应权限**，对着第七节《权限对照表》找管理员加。

## 三、十分钟跑通主线

顺序：**建客户 → 建商品 → 建仓库 → 开销售单 → 下采购单 → 收货入库 → 出货出库 → 财务对账**。

### 第 1 步 · 建客户

进入 **👤 客户管理** → 右上角 **新增客户**：

1. 抽屉里填**客户名称**（必填）、简称、税号、行业、结算方式（如「月结30天」）；
2. **客户类型**选「企业」或「个人」；
3. **结算币种**默认 CNY，也支持 USD / EUR；
4. **信用额度**按需填（目前只做记录，不卡单）；
5. **保存**。

> 系统会生成一个客户编号（留空自动生成）。**编号不能重复**，重复会报「客户编号已存在」。
> 保存后去列表点 **详情**，还能在「联系人 / 地址 / 跟进记录」三个页签里继续补：
> - **联系人**：姓名、岗位、电话、邮箱、微信，可勾「首要联系人」；
> - **地址**：分「收货 / 开票」类型，可设默认地址；
> - **跟进记录**：打电话/拜访后记一条，填跟进方式、摘要、下次动作。

### 第 2 步 · 建商品

进入 **📦 商品** → **新增商品**：

1. 填**商品名称**（必填）、规格型号、单位（默认「件」）、条码；
2. **分类**从下拉里选（分类需已有数据）；
3. 三个价格务必都填：**售价**、**采购价**、**成本价**；
   - 开销售单时默认带出「售价」，开采购单默认带出「采购价」；
4. 填**最低库存**（用于安全库存预警）、**税率(%)**；
5. **保存**。

> 商品编号同样留空自动生成、不能重复。

### 第 3 步 · 建仓库

进入 **📦 仓库** → **新增仓库**：填**仓库编号**、**仓库名称**（都必填）、位置、负责人、电话。

这一页有三个页签，后面天天要用：

| 页签 | 看什么 |
|---|---|
| **仓库** | 仓库清单，可编辑 |
| **库存余额** | 每个仓库每个商品的「库存 / 可用」，可按商品编码或名称搜索 |
| **出入库流水** | 所有入库 / 出库 / 调整记录，含结存与来源 |

> ⚠️ **没有仓库，采购订单收不了货、销售订单出不了货**。上线第一步必须建好仓库。

### 第 4 步 · 开一张销售订单

进入 **📄 销售订单** → **新建订单**：

1. 选**客户**（必填），填下单日期、交货日期、币种、折扣、备注；
2. 在**商品明细**里点 **添加商品**，从下拉选商品，填数量和单价（默认带售价）；
3. 下方自动算出**小计 / 税额 / 合计**；
4. 点 **保存订单**。

保存后回列表，单据状态是 **草稿**。找到它：

- 列表操作列点 **确认**（或进详情点 **确认订单**）→ 状态变 **已确认**；
- 只有**已确认**的单子才能出库。

### 第 5 步 · 下采购订单

进入 **🛒 采购订单** → **新建采购订单**：选**供应商**（必填），填下单日期、期望到货、币种、折扣，添加商品明细（默认带采购价），**保存采购订单**。

回列表 → 点 **详情** → 点 **确认订单** → 状态变 **已确认**。

### 第 6 步 · 收货入库

在采购订单详情页（状态为 **已确认** 或 **已收货**）→ 点 **收货入库**：

1. 抽屉里选**仓库**（必填），填收货日期、承运商、物流单号；
2. **保存**。

**系统会发生什么**：

- 生成一张**收货单**，订单明细的「已收」数量被回写；
- 订单状态变 **已收货**；
- 对应仓库的**库存余额增加**，「出入库流水」多一条 **入库** 记录；
- 自动为该商品建一个**批次号**，并写入追溯事件；如果填了序列号，序列号状态为 **在库**。

> 一张订单可以多次收货（分批到货），未收完的数量会继续挂着。

### 第 7 步 · 出货出库

回销售订单详情页（状态为 **已确认** 或 **已完成**）→ 点 **生成出货单**：填出货日期、收货人、电话、地址，**保存**。

此时只是「生成了出货单」，库存还没动。真正扣库存要走**出货确认**：

- 生成的出货单状态为 **待处理**，确认出库后才会扣减对应仓库库存；
- 出库时系统按**先进先出**从批次里扣量，批次扣完自动置为 **已用完**；
- 序列号商品出库后状态变 **出库**；
- 「出入库流水」会多一条 **出库** 记录。

> 出库确认需要**仓库**的写权限，仓管操作时对不上按钮就是缺权限。

### 第 8 步 · 财务对账

进入 **💰 财务**。顶部四张卡片先看全局：**应收余额、应付余额、累计收款、累计付款**。

五个页签对应全流程：

| 页签 | 操作 |
|---|---|
| **销售发票** | **新增销售发票**（可挂到某张销售订单）→ 列表点 **收款** 登记回款 |
| **采购发票** | **新增采购发票**（可挂到某张采购订单）→ 列表点 **付款** 登记付款 |
| **收付款记录** | 所有收款 / 付款流水 |
| **应收账款** | 每张发票的未结余额与状态 |
| **应付账款** | 同上，采购侧 |

登记收款时：

- 收款金额**不能超过未收余额**，超了会提示；
- 收满后发票状态变 **已结清**，对应的**应收账款**同步结清；
- 若这张发票挂在销售订单上，**订单的收款状态**会同步更新为 **部分收款** 或 **已收清**。

到这一步，**客户 → 商品 → 订单 → 采购 → 入库/出库 → 财务** 的闭环就跑通了。

## 四、日常操作速查

### 客户管理

- **新增客户 / 编辑 / 删除** —— 列表右上角与操作列；删除是软删除，历史单据不受影响。
- **详情** —— 进详情页维护联系人 / 地址 / 跟进记录。
- 列表支持按**关键词**（名称 / 编号 / 简称）搜索，按**状态**（启用 / 停用）过滤。

### 商品

- **新增 / 编辑 / 删除**；按关键词（名称/编号/型号）搜索。

### 销售订单

| 动作 | 位置 | 结果 |
|---|---|---|
| 新建订单 | 列表右上角 | 生成草稿 |
| 确认 | 列表操作列；草稿可见 | 状态 → **已确认** |
| 生成出货单 | 详情页；**已确认/已完成**可见 | 生成 **待处理** 出货单 |
| 看详情 | 列表操作列 | 看金额、收款状态、汇率与双币金额 |

### 采购订单

| 动作 | 位置 | 结果 |
|---|---|---|
| 新建采购订单 | 列表右上角 | 生成草稿 |
| 确认订单 | 详情页；草稿可见 | 状态 → **已确认** |
| 收货入库 | 详情页；**已确认/已收货**可见 | 生成收货单、库存增加、状态 → **已收货** |

### 仓库

- 三个页签切换：**仓库 / 库存余额 / 出入库流水**；
- 流水可按 **入库 / 出库 / 调整** 过滤。

### 财务

- 收付款只能按发票登记，**先有发票才有收付款**；
- 发票未结清的余额，会在 **应收账龄** 里按到期日自动分桶。

## 五、进阶模块速查

主链之外的功能，每个一句话说明门槛与结果：

### 采购申请与审批

| 步骤 | 怎么做 | 结果 |
|---|---|---|
| 1 | **采购申请** → **新建申请**：填标题、申请人、部门、需用日期、紧急程度（普通/紧急/特急）、理由，添加物料明细 | 生成草稿 |
| 2 | 操作列 **提交** | 状态 → **待审批** |
| 3 | 有审批权限的人点 **通过** / **驳回** | 状态 → **已批准** / **已驳回**（驳回带原因） |
| 4 | 已批准的单子点 **转PO** | 自动生成一张采购订单，申请状态 → **已转订单** |

> 申请编号、审批人、审批时间、驳回原因都在详情里留痕。只有草稿或已驳回可删除。

### 制造 · 生产

- **制造**页五个页签：**BOM**（物料清单，含版本、产出数量、启用状态）、**生产工单**（计划数量/已完工/状态）、**工序报工**、**质检**、**MRP可用量**。
- 生产工单状态：**草稿 → 已下达 → 生产中 → 已完成**，另有 **已取消**。
  - 草稿或已取消可点 **下达**；已下达/生产中可 **领料**、**完工**、**报工**。
- **制造深化**：**工作中心**（产能）、**工艺路线**（多工序，每序指定工作中心）、**排产计划**（按工单排产，可 **开工 / 完工**，状态 计划/进行中/已完成/已跳过）。
- **生产报工**菜单：**报工登记**（报工数、合格、不良、工时、操作工）、**工序验收**（待验收 → **通过 / 驳回**）、**工单看板**。

### 库存相关

- **仓储深度**：**库位**、**批次**（在库/已过期/冻结/已用完）、**序列号**（在库/出库/报废）、**盘点**（草稿/盘点中/已完成，可确认盘点）、**安全库存预警**（低于商品最低库存会列出）。
- **调拨预留**：**调拨单**（选调出仓、调入仓、商品数量，草稿 → 点 **执行** 后才真正搬库存，调出仓不足会拦住）；**库存预留**（给别人留货，状态 生效 → 可 **释放** 或 **核销**）。
- **库存结转**：**库存期初**（按期间录入账面期初，草稿 → **确认** 生效）、**月末结转**（先 **计算预览**，确认无误再 **提交结转落库**）、**结转记录**。
- **序列批次追溯**：选 **序列号** 或 **批次号**，输入号码回车，看到该物料的**全生命周期事件时间线**（采购入库、销售出货、调拨等）。

### 财务进阶

- **应收账龄**：**账龄分析**按客户分成「未到期 / 逾30天 / 逾60天 / 逾90天 / 逾90天+」，给出逾期合计与最长逾期天数；**应收明细**可按账龄区间筛选并点 **催收**；**催收记录**登记方式（电话/上门/邮件/在线）与结果（承诺还款/拒绝/未接通/继续跟进）。
- **总账**：先点 **初始化科目** 生成标准科目表；**记账凭证**（草稿 → **保存并过账**）；**账簿分录**可按科目查余额汇总；**会计期间**可结账；**三大报表**一键生成 **资产负债表 / 利润表 / 现金流量表**。
- **多币种汇率**：**币种字典** 维护币种与「本位币」标记；**汇率维护** 按「基准币 → 目标币 + 生效日期」登记汇率；单据保存时按当刻汇率**折算成本位币并留快照**，列表能看到「≈ 折合本位币」。
- **固定资产**：**资产卡片**（原值、残值率、折旧方法：直线法/双倍余额递减、使用年限、开始折旧日）；**折旧记录** 页点 **计提该期折旧** 批量生成；卡片可 **处置**（报废等）。

### 设备与质量

- **设备管理**六个页签：**设备台账**、**点检计划 / 点检记录**、**保养计划 / 保养记录**、**维修工单**（可 **完成**，状态 待处理/处理中/已完成/已关闭）。
- **质量管理**：**检验单**（类型 来料IQC / 制程IPQC / 成品FQC，草稿 → 点 **判定** 出结论）、**不合格品**（登记后可 **处置**）。

### 价格策略

- **价格折扣**：**价目表**（建表后加明细）、**价格试算**（选商品数量一键算价）、**折扣规则**。适合有分级客户价、促销价的公司。

## 六、管理员设置

ERP 没有复杂的「开关」，管理员主要做三件事：

1. **配权限**：在角色里勾选对应权限码（见第七节），分配给业务员、采购、仓管、财务等岗位。
2. **铺基础数据**（顺序很重要，缺一样下游都做不了）：
   - 仓库 → 商品 → 客户、供应商 → 会计科目（总账里点 **初始化科目**）→ 币种与汇率 → 价格表。
3. **期初与结账**：
   - 上系统前先在 **库存结转 → 库存期初** 录入各仓库各商品的期初数量与成本，点 **确认**；
   - 每月末在 **库存结转 → 月末结转** 先预览再落库；
   - 总账在 **会计期间** 里按期结账。

> ⚠️ **已被单据引用的商品、客户、供应商不建议删除** —— 用「停用」代替，删除会让历史单据看不清。

## 七、权限对照表

应用声明的权限码共 **31 个**。表格按「权限 → 能做什么」列：

|---|---|
| `erp:customer:read` | 查看客户、联系人、地址、跟进记录 |
| `erp:customer:write` | 新增 / 修改客户及联系人、地址、跟进 |
| `erp:customer:delete` | 删除客户 |
| `erp:supplier:read` | 查看供应商 |
| `erp:supplier:write` | 新增 / 修改供应商 |
| `erp:product:read` | 查看商品、商品分类 |
| `erp:product:write` | 新增 / 修改商品 |
| `erp:product:delete` | 删除商品 |
| `erp:quotation:read` | 查看报价单 |
| `erp:quotation:write` | 新增报价单、报价转订单 |
| `erp:sales_order:read` | 查看销售订单、出货单 |
| `erp:sales_order:write` | 新增 / 修改销售订单、生成出货单 |
| `erp:sales_order:confirm` | 确认销售订单 |
| `erp:purchase:read` | 查看采购相关数据 |
| `erp:purchase:write` | 采购相关写操作 |
| `erp:warehouse:read` | 查看仓库、库存余额、出入库流水、调拨、盘点、追溯 |
| `erp:warehouse:write` | 仓库增改、收货入库、出货确认出库、调拨执行、盘点、预留 |
| `erp:warehouse:delete` | 删除仓库、调拨单等 |
| `erp:finance:read` | 查看发票、收付款、应收应付、账龄、汇率 |
| `erp:finance:write` | 开发票、登记收付款 |
| `erp:finance:delete` | 删除财务记录 |
| `erp:gl:read` | 查看科目、凭证、报表、固定资产 |
| `erp:gl:write` | 建科目、录凭证并过账、计提折旧、期间结账 |
| `erp:gl:delete` | 删除总账 / 资产数据 |
| `erp:pr:read` | 查看采购申请 |
| `erp:pr:write` | 建申请、提交审批、转采购订单 |
| `erp:mfg:read` | 查看 BOM、工单、排产、报工、设备、质量 |
| `erp:mfg:write` | BOM / 工单 / 领料完工 / 报工 / 排产 / 设备 / 质量等全部制造写操作 |
| `erp:cost:read` | 查看成本期间、核算结果、归集明细 |
| `erp:cost:write` | 建成本期间、核算、手工归集 |
| `erp:admin` | 应用管理级权限 |

> **补充（分配角色时请一并勾选）**：部分动作实际校验的是更细的权限码，未列在上表中 —— 采购订单要用订单级的 **读 / 写 / 确认** 三个码；采购申请的 **审批** 和 **删除** 各有单独权限；制造的 **删除** 也是单独权限。给采购、生产主管配角色时，除了上表的采购、制造权限，记得把这几项也勾上，否则「确认订单 / 审批 / 删除」按钮点了会失败。

**推荐角色模板**：

| 角色 | 建议权限 |
|---|---|
| 业务员 | 客户全部 + 商品读 + 销售订单读/写/确认 + 价格读 |
| 采购员 | 供应商写 + 商品读 + 采购读写、订单确认 + 采购申请读写 + 仓库读 |
| 仓管 | 仓库读写 + 仓储深度 + 调拨预留 + 库存结转 + 追溯 |
| 财务 | 财务读写 + 总账读写 + 应收账龄 + 多币种 + 固定资产 |
| 生产主管 | 制造全部 + 生产报工 + 成本核算 + 设备 + 质量 |
| 管理员 | 全部权限 + `erp:admin` |

## 八、常见问题

**Q：左侧看不到「ERP 管理」？**
没有该应用的访问权限，找管理员在角色里挂上对应权限，权限实时生效，不用重新登录。

**Q：采购订单点「确认订单」或「收货入库」没反应 / 报错？**
两种常见原因：① 缺权限（采购订单的确认、写权限）；② 还没建仓库 —— 收货必须先有仓库，去 **仓库** 菜单建一个。

**Q：销售订单点「生成出货单」按钮是灰的 / 不显示？**
只有 **已确认** 或 **已完成** 状态的订单才会出现该按钮。草稿订单先去列表点 **确认**。

**Q：生成出货单后，库存为什么没变？**
生成出货单只是**开单**，还没出库。要到出货单上做 **确认出库**，库存才会扣减，且要求有仓库写权限。

**Q：收货后库存余额里没看到数量？**
收货时选的仓库和你在「库存余额」里查的仓库是不是同一个？收货按仓库入账，换仓库页签核对一下。

**Q：客户的应收挂在哪看？欠多久了？**
**应收账龄 → 账龄分析**，选分析日期刷新，按客户给出未到期与各逾期区间金额；**应收明细** 可按账龄区间筛选，点 **催收** 记一条催收记录。

**Q：外币订单的金额怎么看本位币？**
先在 **多币种汇率** 里维护币种和汇率，并标记本位币。单据保存时会按当时汇率折算并**存快照**，详情页合计旁边会显示「≈ 折合本位币」，之后改汇率也不会影响已保存的单据。

**Q：采购申请提交了，审批人是谁？**
审批按角色的 **采购申请审批** 权限走。没有该权限的人点「通过 / 驳回」会失败；批完才能 **转PO** 生成采购订单。

**Q：生产工单点不了「领料 / 完工」？**
先点 **下达**。只有 **已下达** 或 **生产中** 的工单才能领料、完工、报工。

**Q：盘点、月末结转做完能改吗？**
盘点单确认、期初确认、期间结账这些是**一次性**动作，落库即为最终值。做之前先 **预览**，确认无误再提交。

**Q：删了客户 / 商品，历史单据会怎样？**
删除是**软删除**，历史单据仍保留，但列表里不再显示该主数据。对已在用的主数据，建议改成 **停用** 而不是删除。
