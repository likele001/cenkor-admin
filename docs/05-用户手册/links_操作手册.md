# 链接收藏 · 操作手册

> **给谁看**：想给团队攒一份常用网址清单的人。
> 全文按界面上实际点的位置写 —— 每一步都说清「点哪里 → 看到什么 → 填什么」。

---

## 一、这个模块解决什么问题

把散落在浏览器收藏夹、聊天记录里的网址集中存起来：按分类归好、给常用的加星，谁需要谁去列表里点。
适合攒一份**团队共用的资源库** —— 文档站、后台地址、设计稿、常用工具。

---

## 二、从哪儿进

后台左侧菜单 → **链接收藏**（🔗）→ **链接列表**。

| 菜单 | 路径 | 谁能进 |
|---|---|---|
| 链接收藏 → 链接列表 | `/links` | 有 `links:read` 权限即可查看 |

> 想**添加 / 编辑 / 删除 / 加星**，还需要 `links:write`。
> **看不到菜单 = 没有权限**，找管理员加。

---

## 三、怎么用

### 添加一条链接

1. **链接列表** 右上角点 **添加链接**；
2. 弹窗里填写：

   | 填什么 | 说明 |
   |---|---|
   | **URL** | 必填。可以只写 `docs.example.com`，系统会**自动补上 `https://`** |
   | **标题** | 可选。留空时**自动用 URL 当标题** |
   | **分类** | 通用 / 开发 / 设计 / 文档 / 工具 |
   | **描述** | 富文本，可选，写点用途备注 |
   | **收藏** | 勾选框，勾上等于加星 |

3. 点 **保存**。

### 打开链接

列表里 **URL** 那一列是超链接，点一下会**在新标签页**打开，不会离开后台。

### 加星 / 取消星标

每行**最左边的 ☆ / ★ 按钮**，点一下即切换：

- ☆（灰色）= 未收藏；★（黄色）= 已收藏；
- **加星的链接会排到列表最前面**，方便最先看到。

### 改分类、改标题

点 **编辑** → 调整 **分类**、**标题** 或描述 → **保存**。

### 搜索与筛选

列表上方：**搜索框**输入标题或 URL 关键词，**分类**下拉选一类，点 **搜索**（搜索框里也能直接按回车）。

### 删除

点 **删除** 并确认，链接从列表移除。删除是**软删除**，但页面没有回收站入口 —— 误删要联系管理员从后台恢复。

## 四、字段与状态说明

| 字段 | 可选值 / 说明 |
|---|---|
| URL | 必填；不带 `http(s)://` 会自动补 `https://` |
| 标题 | 留空则显示 URL |
| 分类 | 通用 / 开发 / 设计 / 文档 / 工具（带颜色标签） |
| 描述 | 富文本备注 |
| 收藏 | 是（★）/ 否（☆） |
| 访问 | 数字，记录字段 |
| 添加时间 | 列表按它排序 |

**排序规则**：先收藏、再按添加时间倒序。

## 五、常见问题

**Q：为什么大家看到的是同一份列表？**
链接收藏是**团队共享**的，只要登录且有查看权限就能看到全部链接 —— 它适合攒公共资源库，**不适合放私人网址**。

**Q：点 URL 打不开？**
可能是网址本身失效，或协议头不对。编辑该条，把 URL 补成完整形式（`https://...`）再试。

**Q：为什么「访问」次数一直是 0？**
当前版本不会自动累加，属已知现象，不影响使用。

**Q：描述是富文本，可列表里看不到？**
描述只在编辑弹窗里维护；列表重点展示标题和 URL，所以不显示描述。

**Q：分类不够用？**
当前分类是固定的五类。请先归到「通用」，同时找管理员反馈新增。

**Q：加星按钮点了没反应？**
缺少 `links:write` 权限，找管理员加。
