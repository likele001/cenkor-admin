# 通知 · 操作手册

> **给谁看**：所有登录后台的人。通知是系统「主动告诉你」的通道。
> 全文按界面上实际点的位置写 —— 每一步都说清「点哪里 → 看到什么 → 做什么」。

---

## 一、这个模块解决什么问题

把「工单分配给你了」「你的工单有评论」「工单状态变了」这类**需要你本人知道**的事，集中推给你，并在**顶栏右上角用小红点**提醒。
每条通知**按人隔离** —— 你只看得到发给自己的，别人看他们的。

它和「公告」的区别：公告是所有人共享的公告板；通知是**一对一**推给你的消息。

---

## 二、从哪儿进（两个入口）

| 入口 | 位置 | 能做什么 |
|---|---|---|
| 🔔 **通知铃铛** | **顶栏右上角**，所有页面都能看到 | 下拉快速看最近的通知，红角标 = 未读条数 |
| **通知管理** | 左侧菜单 → **系统** → **通知管理** | 完整列表（带分页），可只看未读、批量已读，有权限还能发通知 |

> - 铃铛未读数**每 30 秒自动刷新一次**；
> - 若系统已开启实时推送，新通知会**立刻**在铃铛里冒出来，不用手动刷新；
> - 两个入口看的是**同一批数据**。
> - 两个入口都需要 `notification:read` 权限；**没权限时铃铛不显示**。

## 三、怎么用

### 看通知

- 点顶栏 **🔔** → 下拉显示**最近 20 条**。**未读的标题前有蓝点**，整条背景带浅色；
- 或者进 **系统 → 通知管理** 页面看**完整列表**（条目多时可翻页）。

### 标记已读

| 想做什么 | 怎么做 |
|---|---|
| 标记**单条** | 鼠标移到条目上 → 点 **已读**（铃铛下拉和通知管理页都有） |
| 全部标记 | 铃铛下拉右上角 **全部标为已读**；或通知管理页的 **全部已读** |

已读之后蓝点消失、条目变灰，铃铛上的红点数字同步减少。

### 只看未读

在 **通知管理** 页面，右上角点 **只看未读** —— 切过去后就只列未读；再点一次（按钮变成 **查看全部**）恢复看全部。

### 跳转到相关页面

**通知管理页**里，如果这条通知带了链接（例如工单通知），条目下方会出现 **查看**，点它**直接跳到对应页面**（工单通知会跳到工单列表）。

> 铃铛下拉里只做「看一眼 + 已读」，**不提供跳转**；要跳转请去通知管理页。

### 删除通知

每条右侧点 **删除**，删掉后不再显示（铃铛下拉里鼠标移上去才出现 **删除**）。

### 发送通知（管理员）

**通知管理** 页 → 右上角 **发送通知**：

1. **类型**：系统通知 / 任务通知；
2. **标题**（必填）、**内容**（可选）、**链接**（可选，填一个站内路径，例如工单列表）；
3. 点 **发送给所有人** —— 这个按钮是给**全体成员**每人发一条。

## 四、字段与状态说明

| 字段 | 说明 |
|---|---|
| **类型** | **系统** / **审计** / **提及** / **任务**（列表里带颜色标签） |
| **已读状态** | **未读**（标题前有蓝点、有红角标）/ **已读**（变灰） |
| **时间** | 铃铛下拉显示相对时间：刚刚 / x 分钟前 / x 小时前 / x 天前 |
| **链接** | 通知管理页里显示为 **查看** 按钮 |

### 通知都是从哪儿来的

| 触发场景 | 谁收到 | 类型 |
|---|---|---|
| 新建工单时指定了处理人 | 被指定的处理人 | 任务 |
| 工单被改派给别人 | 新的处理人 | 任务 |
| 工单状态被**他人**变更 | 工单的创建人 | 任务 |
| 工单有**他人**评论 | 创建人 / 处理人 | 任务 |
| 评论里写了 `@某人` | 被提到的那个成员 | 提及 |
| 管理员在通知管理页手动发送 | 指定的人或全员 | 系统 / 任务 |

## 五、常见问题

**Q：顶栏没有铃铛，点开也没有内容？**
多半是没有 `notification:read` 权限 —— 铃铛本身在有权限时才显示。找管理员加权限。

**Q：为什么我只能看到自己的通知？**
通知**按人隔离**，每个人只看得到发给自己的那部分，这是设计如此。

**Q：红点数字一直不消失？**
红角标表示**未读条数**，读了才会减。点 **全部已读**/**全部标为已读** 即可清零。

**Q：发出去的工单通知对方没收到？**
按顺序排查：① 对方是否有 `notification:read` 权限；② 通知是**按人**投递的，让对方在铃铛里（或通知管理页）刷新看看；③ 若改状态的人就是工单创建人本人，则不会给自己发通知。

**Q：普通人都能发通知吗？**
不能。只有拥有 `notification:write` 权限的人才能看到 **发送通知** 按钮；普通用户只能查看和标记已读。
