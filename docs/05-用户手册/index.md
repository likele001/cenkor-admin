## 三、三条通用约定

1. **看不到某个菜单 = 没有对应权限**，不是系统坏了。找管理员按对应手册里的《权限对照表》加。
2. **保存 ≠ 生效** 这件事在这个系统里反复出现：模板要「设为生效」、内容要「已发布」、规则改完要看前台。手册里每处都会标出来。
3. **拿不准就先看预览**：模板有预览、内容有暂存预览、网址规则有预览。凡是带预览的，先看再存。
