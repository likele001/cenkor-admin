# CRM 销售管理 · 操作手册

> **给谁看**：跑客户的销售、管销售的销售主管、维护客户资料的销售助理。
> 全文按**界面上实际点的位置**写 —— 每一步都说清「点哪个菜单 → 页面上做什么 → 系统会发生什么」。
> 想改这个应用的代码看《二次开发指南》；想安装 / 升级看《部署方案》。

---

## 一、这个模块解决什么问题

把「从一条线索到收到钱」这件事放在同一个地方：

| 环节 | 菜单 | 一句话说明 |
|---|---|---|
| 找潜在客户 | 销售线索 | 线索先躺在**公海**，谁想跟谁**认领**；跟不动就**退回公海** |
| 建客户档案 | 客户档案 / 联系人 | 客户主数据 + 对接人，报价、工单都挂在这上面 |
| 推进成交 | 商机 | 按阶段推进，列表和看板两种视角 |
| 报价送审送 ERP | 报价/合同 | 报价单可**提交 → 审批 → 推ERP**，推过去在 ERP 里生成一张报价单 |
| 收钱 | 回款计划 | 分期计划 + 实际到账，收满自动变「已收齐」 |
| 售后 | 服务工单 | 带 SLA 倒计时的对话式工单 |
| 看盘 | 销售仪表盘 | 8 张 KPI 卡 + 商机漏斗 + 业绩排行 |

先记住三件事，后面会反复用到：

- **销售线索和客户档案是两套数据**，互不自动打通 —— 客户要自己在「客户档案」里建。
- **线索分公海 / 私海**：公海＝无人认领，私海＝有人负责；私海久不跟进会自动回公海。
- **报价不会自动变成回款计划**，回款计划独立建，靠「报价单ID」手动挂上。

| 👛 回款计划 | `/crm/payment-plans` | 建分期计划、录入实际回款 | 所有人 |

## 三、十分钟跑通一条销售主线

顺序：**线索 → 客户 → 联系人 → 商机 → 报价 → 回款计划 → 服务工单**。

### 第 1 步 · 录一条线索

**销售线索 → 新增线索**：填 **线索名称**（必填）、**公司**、**联系人**、**手机**、**电话**、**邮箱**，
选 **来源**（手动 / 官网 / 转介绍 / 广告 / 展会 / 导入）、**意向度**（高 / 中 / 低），填 **城市**、**备注**，保存。

结果：线索进 **公海**（列表「所属」列显示 `公海`），状态 **新建**。

### 第 2 步 · 认领 / 分配

列表上方用 **全部 / 公海 / 私海** 切换找线索，行操作四个按钮：

| 按钮 | 结果 |
|---|---|
| **认领** | 变私海、负责人＝我，状态从「新建」变 **已联系** |
| **分配** | 主管/助理用，直接把负责人改成指定的人 |
| **退回公海** | 清空负责人、回收进公海，状态变 **已回收**（只有负责人或管理员能退） |
| **删除** | 软删除，列表不再显示 |

### 第 3 步 · 建客户档案

**客户档案 → 新增客户**：

- **客户编号**留空自动生成（`C+年月日+4 位序号`）；
- 必填 **客户名称**；其余按需填：**简称**、**客户类型**（企业 / 个人）、**税号**、**结算币种**（CNY/USD/EUR/JPY）、
  **信用额度**、**客户级别**（A/B/C/D 类）、**规模**（微型/小型/中型/大型）、**所属行业**、**结算条款**（如「月结30天」）、
  电话/邮箱/省市区/详细地址、**客户状态**（启用 / 停用）、备注。

> ⚠️ **线索不会自动变成客户**。界面上目前没有「线索转客户」按钮（后端具备该能力，前端未开放），
> 请照线索里的公司名、电话手工建客户。

### 第 4 步 · 加联系人

**客户档案** → 找到客户 → **编辑** → 下方 **联系人** 区 → **+ 添加联系人**：
填 **姓名**、**职务**、**手机**、**邮箱**，第一条默认勾成**主要联系人**，保存时随客户一起提交。

> 「联系人」菜单是**只读查询页**（查出客户 → **查看联系人** 弹抽屉看对接人）。
> 增删改联系人都走「客户档案 → 编辑」。

### 第 5 步 · 建商机并推进

**商机 → 新增商机**：填 **商机名称**、**客户ID**、**金额**、**阶段**、**概率**、**预计关单**、**竞品**、**产品摘要**、**备注**。
页面上方可切 **列表 / 看板**（看板把各阶段铺成列，一眼看管道形状）。

推进方式有两种，**行为完全不同**：

| 方式 | 操作 | 系统做什么 |
|---|---|---|
| **切阶段** | 列表行 → **切阶段** | 改阶段，**并自动写一条跟进记录**；`赢单` 置概率 100、`输单` 置 0，同时回填实际关单日 |
| **详情（编辑）** | 列表行 → **详情** → 改 **阶段** → 保存 | 只改阶段，**不写跟进、不改概率** |

> ⚠️ 两个坑：① **「切阶段」下拉里没有「赢单 / 输单」** —— 收尾要走 **详情 → 阶段** 改再保存；
> ② 商机一旦是 **赢单 / 输单**，「切阶段」按钮消失，阶段也改不了了。

### 第 6 步 · 报价 → 审批 → 送 ERP

**报价/合同 → 新建报价**：

1. 填 **标题**、选 **CRM客户**（必填）、**币种**、**报价日期**、**有效期至**；
2. 填 **ERP客户ID**（留空的话，推 ERP 时会去取 CRM 客户上绑的 ERP 客户）；
3. 在 **报价明细** 逐行填 **品名/服务**、**SKU**、**数量**、**单价**、**税率**（默认 13），**+ 添加明细** 加行；
4. 保存 → 生成一张 **草稿** 报价单。

金额规则（页面实时显示）：`明细金额 = 数量 × 单价 × (1 - 该行折扣%)`，
`合计 = 明细金额之和 + 税额 - 整单折扣`。

然后按顺序推进：

| 按钮 | 状态变化 | 说明 |
|---|---|---|
| **提交** | 草稿 → **已提交** | 只有草稿能提交 |
| **审批** | 已提交 → **已审批** | 需审批权限；草稿也能直接审批 |
| **推ERP** | 已审批 → **已推送ERP** | 在 ERP 生成一张报价单（编号 `CRT-` ＋CRM 报价编号） |

推 ERP 的两个拦路虎：**状态必须是「已审批」或「草稿」**；**必须有 ERP 客户**（手填 Erp客户ID，或 CRM 客户已关联 ERP 客户）。
**推过的单子不能重复推**。

### 第 7 步 · 做回款计划并录入到账

**回款计划 → 新增回款计划**：填 **客户ID**、**报价单ID**（可留空）、**期次**、**标题**（首款 / 中期款 / 尾款）、
**应回款额**、**到期日** → 保存，状态 **待收款**。

收到钱 → 行上点 **录入回款**：填 **收款金额**、**收款日期**、**方式**（银行转账 / 现金 / 支票 / 支付宝 / 微信）、
**流水号** → 确定。系统自动累加并改状态：

| 已收金额 | 计划状态 |
|---|---|
| 0 | 待收款 |
| 收了一部分 | **部分收款** |
| 收满（≥ 应回款额） | **已收齐** |

> ⚠️ 录入金额**不能超过计划金额**，超了直接报错。录错了删掉那条回款记录，已收金额和状态会自动回退。

### 第 8 步 · 开工单（有售后才做）

**服务工单 → 新建工单**：选 **关联客户**、**类型**（维修 / 咨询 / 投诉 / 退换货 / 其他）、
**优先级**（紧急 / 高 / 中 / 低），填 **主题**、**描述**。保存后状态 **待处理**。

**SLA 截止时间自动算**（也可手填覆盖）：紧急 240 分钟、高 480、中 1440、低 2880。

处理流程：列表 → **处理** → 进详情页：

| 动作 | 结果 |
|---|---|
| **改派** | 指定处理人；「待处理 / 等待客户」自动变 **处理中**，并落一条系统消息 |
| **发送回复** | 加一条对话；可勾 **内部**（只给同事看）；「待处理」自动转 **处理中** |
| **标记解决** | 状态变 **已解决**，记下解决时间 |
| **关闭工单** | 状态变 **已关闭**，可顺手打 **1~5 分**满意度 |

> 已关闭 / 已取消的工单**不能再回复或修改**。

## 四、日常操作速查

**销售线索**
- **认领**只能对公海线索点，否则提示「线索不在公海，无法认领」；**退回公海**会把状态改成 **已回收**。
- 公海回收机制：私海线索超过 **占用天数**（默认 30 天）没有跟进，会被回收任务自动放回公海。

**客户档案**：行操作 **详情** / **编辑**（含联系人维护）/ **删除**；客户状态有 启用 / 停用 / 流失。

**商机**：**列表** 适合筛选和批量看，**看板** 适合按阶段看管道；「这笔黄了」＝ 详情 → 阶段改 **输单**。

**报价/合同**：状态一眼看 草稿 / 已提交 / 已审批 / 已驳回 / 已推送ERP；**已推送 / 已作废的报价不能再改**。

**回款计划**
- 状态筛选：待收款 / 部分收款 / 已收齐 / 已逾期 / 已取消。
- ⚠️ 「已逾期」**系统不会自动打标**，判断逾期要自己看 **到期日** 和已收金额。
- **取消** 是作废计划，**删除** 是软删除，都在行操作里。

**服务工单**：状态 待处理 / 处理中 / 等待客户 / 已解决 / 已关闭；SLA 提示 **正常 / 即将超时 / 已超时**。

## 五、进阶用法

**销售仪表盘**：8 张卡片 —— 客户总数、销售线索（公海/私海分子）、进行中商机、销售管道、
赢单金额、已回款、待处理工单（含超 SLA 数）、待跟进；下面两块是 **商机漏斗**（可按负责人筛）和 **业绩排行**。

**跟进记录（只读）**：对象可以是 **线索 / 客户 / 商机 / 联系人 / 工单**，每条含跟进 **方式**
（电话 / 微信 / 邮件 / 拜访 / 其他）、**结果**（积极 / 中性 / 消极）、标题、内容、跟进人、时间，默认按时间倒序展示最近 200 条。
**推进商机阶段时系统会自动补一条**，所以它能当销售动作的审计日志看。

**批量导入 / 导出**（在 **外部对接** 里）：**导出客户 / 导出线索** 出 CSV（UTF-8 BOM，Excel 打开不乱码）；
**按模板批量导入** 先 **下载模板** → 填好 → **选择文件** → 看 **导入结果**（成功多少条、失败原因）。

**和 ERP / 第三方打通**：报价单审批后可一键 **推ERP**；关键动作还能推 **Webhook** 给第三方（事件清单见下一节）；
平台另开放一组以只读为主的**对外 Open API**（客户查/建/改、线索查/建、商机查、报价查、工单查），用「外部对接 → API 密钥」里发的密钥鉴权。

## 六、管理员设置

### CRM 设置

**CRM 设置** 页有 5 项：**私海线索占用天数**、**出厂 SLA（小时）**、**超时告警**、
**线索转化自动建商机**、**商机赢单后提示创建回款计划**，改完点 **保存设置**。

> ⚠️ **这一页的设置目前只保存在你自己的浏览器里**（本地存储），换电脑、换浏览器就看不到，
> 也**不会真正影响后台**的回收 / SLA 计算（真正生效的回收周期是每条线索自己的「占用天数」字段）。

### 外部对接（共 4 个板块，都需要 `crm:admin`）

| 板块 | 能做什么 |
|---|---|
| **API 密钥** | 新建（可设过期时间，留空永不过期；可设「读 / 读写」）、复制、**撤销**、删除。密钥只在生成时显示一次，务必当场复制 |
| **Webhook** | 新建 / 编辑 / 删除：填地址、勾选订阅的事件、可配签名头，支持 **测试** 与查 **日志** |
| **同步目标** | 配置推送到第三方 ERP/ES 的目标与字段映射，支持 **测试**、按「只显示这一次」看单次日志 |
| **导入导出** | CSV 批量导入客户 / 线索，导出客户 / 线索 |

Webhook 可订阅的 15 个事件：

```
customer.created / customer.updated / customer.deleted
lead.created / lead.updated / lead.converted
opportunity.created / opportunity.stage_changed
quotation.created / quotation.approved
ticket.created / ticket.replied / ticket.resolved / ticket.closed
payment.recorded
```

| `crm:followup:write` | 写跟进记录 |

| `crm:payment:write` | 新增 / 修改回款计划、录入回款 |
| `crm:payment:delete` | 删回款计划、删回款记录 |

| `crm:ticket:write` | 新建 / 修改工单 |

| `crm:ticket:reply` | 工单里 **回复** |

> 最省事的分配方式：
> **销售** —— `crm:lead:read/write/claim/release`、`crm:customer:read/write`、`crm:opportunity:read/write/stage`、`crm:quotation:read/write`、`crm:payment:read/write`、`crm:ticket:read/write/reply`、`crm:followup:read/write`、`crm:dashboard:read`
> **销售主管** —— 销售的全部，再加 `crm:lead:assign/recycle`、`crm:quotation:approve`、`crm:ticket:assign/resolve`
> **管理员** —— `crm:admin`，需要导出再加 `crm:customer:export`

## 八、常见问题

**Q：菜单里看不到「CRM 销售管理」或某个子菜单？**
没有权限。菜单按权限显示，找管理员在角色里挂上即可，**权限实时生效，不用重新登录**。
**Q：认领线索提示「线索不在公海，无法认领」？**
这条已经是私海（被人认领或分配过）。找现在的负责人，或让他先 **退回公海**。
**Q：客户编号不填行不行？**
可以，留空自动按 `C+年月日+4 位序号` 生成；自己填的话不能和已有的重复。
**Q：我照线索建完客户，为什么线索状态没变？**
线索和客户是两套数据，**建客户不会回写线索**。要改状态就在线索里编辑。
**Q：商机想标赢单，为什么「切阶段」里没有？**
「切阶段」只列了四个推进阶段。赢单/输单走 **详情 → 阶段** 改再保存 ——
注意这条路径**不会**自动把概率改成 100/0，也**不会**写跟进记录。
**Q：报价被驳回了怎么办？**
「已驳回」的单子**不能再提交**（提交只认「草稿」），也推不了 ERP。**重新建一张**，或找管理员把状态改回草稿。
**Q：推 ERP 报「未指定 erp_customer_id，且 CRM 客户也未关联 ERP 客户」？**
在报价单里手填 **ERP客户ID**，或先把 CRM 客户关联到 ERP 客户再推。
**Q：推 ERP 报「已推送到 ERP，请勿重复」？**
一张报价单只能推一次。要改就在 CRM 侧改记录，或到 ERP 里改那张单。
**Q：录入回款报「收款金额超出计划金额」？**
累计收款不能超过应回款额。要么填错了，要么这张计划该拆成几期。删掉那条回款记录会自动回退。
**Q：回款计划筛「已逾期」查不到东西？**
系统不会自动打「已逾期」标记。请按 **到期日** 排一下，结合「待收款 / 部分收款」人工判断。
**Q：工单回复不了？**
已关闭 / 已取消的工单不能回复。想继续沟通就新建一张。满意度只能填 **1~5 分**。
**Q：仪表盘的「待跟进」怎么算的？**
统计**下次跟进时间已经到点**的跟进记录条数（没填下次跟进时间的不算）。

## 附：状态与枚举对照

- **线索状态**：新建 / 已联系 / 已合格 / 已转化 / 已回收 / 已丢弃。
- **商机阶段**：初步接洽 → 资格审查 → 方案报价 → 商务谈判 → **赢单** / **输单**（后两个是终态，不能再改）。
- **报价单状态**：草稿 / 已提交 / 已审批 / 已驳回 / 已推送ERP。**回款计划状态**：待收款 / 部分收款 / 已收齐 / 已逾期 / 已取消。
- **工单**：状态 待处理 / 处理中 / 等待客户 / 已解决 / 已关闭 / 已取消；类型 维修 / 咨询 / 投诉 / 退换货 / 其他；对话来源 客户 / 客服 / 系统（勾「内部」只给同事看）。
