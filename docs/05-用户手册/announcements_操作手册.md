# 公告管理 · 操作手册

> **给谁看**：负责发布公司公告、通知的人，以及需要查阅公告的普通同事。
> 全文按界面上实际点的位置写 —— 每一步都说清「点哪里 → 看到什么 → 填什么」。

---

## 一、这个模块解决什么问题

把张贴在公告栏上的通知搬到系统里：谁发的、什么时候发的、有没有置顶、是草稿还是已发布，列表上一眼看得到。
适合发制度更新、放假通知、系统维护提醒这类**一对多**的消息。

它和「通知」的区别：公告是**所有人共享的公告板**，谁都能看；通知是**一对一推给某个人**的铃铛消息。

---

## 二、从哪儿进

后台左侧菜单 → **公告管理**（📢）→ **公告列表**。

| 菜单 | 路径 | 谁能进 |
|---|---|---|
| 公告管理 → 公告列表 | `/announcements` | 有 `announcements:read` 权限即可查看 |

> 想**新建 / 编辑 / 删除**，还需要 `announcements:write`。
> **看不到菜单 = 没有权限**，找管理员在角色里挂上对应权限，实时生效、不用重新登录。

---

## 三、怎么用

### 新建并发布一条公告

1. 进入 **公告管理 → 公告列表**，右上角点 **新建公告**；
2. 弹窗里从上往下填：

   | 填什么 | 说明 |
   |---|---|
   | **标题** | 必填 |
   | **分类** | 通用 / 系统 / 紧急 |
   | **优先级** | 低 / 普通 / 高 / 紧急 |
   | **摘要** | 可选，仅备查，列表里不展示 |
   | **内容** | 富文本编辑器，支持排版；编辑器下方**实时显示内容预览** |

3. 需要的话勾选下面两个开关：
   - **置顶** —— 勾上后列表标题前出现 📌，并排在最前面；
   - **发布** —— 勾上才算「已发布」；**不勾就是草稿**；
4. 点 **保存**。窗口关闭，列表自动刷新。

> 💡 想「先写好、稍后再发」：保存时**不勾「发布」**，到点再编辑勾上。

### 把公告下线 / 重新上线

1. 列表里找到那条，点 **编辑**；
2. 取消勾选 **发布**（下线）或重新勾选（上线）；
3. **保存**。状态列会从「已发布」变回「草稿」，或反过来。

### 置顶 / 取消置顶

**编辑** → 勾选或取消 **置顶** → **保存**。置顶的公告永远排在非置顶的前面。

### 查找公告

列表上方：**搜索框**输入标题或内容关键词，**分类**下拉选一类，点 **搜索**。

### 修改与删除

- **编辑** —— 改任意字段后保存；
- **删除** —— 点 **删除** 并确认，公告从列表消失。删除是**软删除**，但页面没有回收站入口 —— 误删要联系管理员从后台恢复。

## 四、字段与状态说明

| 字段 | 可选值（界面上看到的） | 说明 |
|---|---|---|
| 分类 | 通用 / 系统 / 紧急 | 便于筛选 |
| 优先级 | 低 / 普通 / 高 / 紧急 | 颜色从灰到红，仅作提示 |
| 状态 | **已发布** / **草稿** | 由「发布」勾选框决定 |
| 置顶 | 是 / 否 | 是则带 📌 并排最前 |
| 浏览 | 数字 | 记录字段 |

**排序规则**：先置顶、再按创建时间倒序（最新的在最上面）。

**状态两条就够用**：

| 状态 | 含义 | 谁能看到 |
|---|---|---|
| 草稿 | 建好了但还没发布 | 有查看权限的人都能看到（只是标着「草稿」） |
| 已发布 | 正式上线 | 同上；是否对外展示由前端页面决定 |

## 五、常见问题

**Q：公告存了却找不到？**
先看状态列是不是「草稿」；如果列表里完全没有，检查搜索框 / 分类筛选是不是把结果过滤掉了 —— 清空条件再点 **搜索**。

**Q：为什么「浏览」一直是 0？**
当前版本浏览数不会自动累加，属已知现象，不影响使用。

**Q：想定时发布怎么办？**
系统层面已预留「计划发布时间 / 过期时间」，但**当前页面没有填写入口**。现在请用「先存草稿 → 到点手动勾发布」的方式来代替。

**Q：公告谁能看到？**
公告是**全公司共享**的，只要有 `announcements:read` 权限就能看到全部条目（含草稿）。

**Q：删错了能恢复吗？**
能。删除只是打标记，数据还在库里；但页面没有回收站入口，需要联系管理员从后台恢复。

**Q：编辑 / 删除按钮点了没反应或报错？**
缺少 `announcements:write` 权限，找管理员加。
