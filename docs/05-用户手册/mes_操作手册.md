# MES 制造执行 · 操作手册

> **给谁看**：车间主任、计划员、调度/班组长、质检员、一线报工工人，以及维护基础数据的工艺员。
> 全文按**界面上实际点的位置**写 —— 每一步都说清「点哪个菜单 → 页面上做什么 → 系统会发生什么」。
> 想改这个应用的代码看《二次开发指南》；想安装 / 升级看《部署方案》。

## 一、这个模块解决什么问题

把「一张生产订单怎么在车间里被干出来」这件事管起来：

| 环节 | 菜单 | 一句话说明 |
|---|---|---|
| 开单 | 生产订单 | 说清「做什么产品、做多少、什么时候要」 |
| 排期 | 生产计划 | 把订单拆成计划单和明细（产品 × 数量） |
| 派活 | 排产派工 | 明细 → 工序任务，派到人 / 机台；可按工艺路线一键生成 |
| 干活 | 生产报工 / 员工报工 | 报合格数、返工数、报废数 |
| 把关 | 质量检验 | 必检工序报工后挂起待检，检验员判定 |
| 算钱 | 计件工资 | 合格数 × 工序计件单价，自动结算 |
| 看现场 | 车间看板 / 概览 | 今日计划、在制任务、今日合格与报废 |
| 查责任 | 质量追溯 | 一批料从入库到出货的全链路时间线 |
| 管设备 | 设备管理 | 设备状态、停机报停与统计 |

三条必须记住的规则（后面全靠它们）：
- **进度是自动回写的**：报工 → 任务 → 计划明细 → 计划 → 生产订单，一级一级往上推，**不用人工改状态**。
- **必检工序的报工先挂起**：数量先进「待检数」，**不计入合格数**，等检验员判定了才落成合格/返工/报废。
- **计件工资只看合格数**：`合格数 × 工序计件单价`；**返工和报废不计件**，工序没填单价就不计件。

## 三、二十分钟跑通一条生产主线

顺序：**基础数据 → 生产订单 → 生产计划 → 排产派工 → 报工 → 质量检验 → 计件工资**。

### 第 0 步 · 把基础数据配一次

**基础数据** 里一次配好，后面长期复用：

| 页签 | 要填什么 | 备注 |
|---|---|---|
| **产品** | 编码、名称、规格型号、单位、分类、是否启用 | **开生产订单必须先有产品** |
| **工序** | 编码、名称、标准工时、**计件单价**（元/件）、**是否必检** | 单价留空或 0 = 不计件；必检 = 报工后待检 |
| **机台/工位** | 编码、名称、类型、位置、产能、人数 | 派工时可指定默认机台 |
| **物料** | 编码、名称、规格、单位、分类 | 供 BOM 引用 |
| **工艺路线** | 绑定产品 + 步骤（步骤顺序、工序、默认机台、标准工时） | 配了它才能「按工艺自动生成工序任务」 |
| **BOM** | 绑定产品 + 子项（物料、单台用量、单位） | 定义这个产品要哪些料 |
| **工人名单** | —— | **只读**，来自平台账号，不用在这里维护 |

### 第 1 步 · 建生产订单

**生产订单 → 新建生产订单**：选 **产品**、填 **应产数量**、**开始日期**、**交期**、**单位**，
可挂一个 **BOM**，填 **备注** → 保存。

结果：系统生成订单号 **`MO+年月日+三位序号`**，状态是 **草稿**；列表会显示关联**计划数**和**进度%**。
点订单进详情，能看到「订单全景」——这个订单下面挂了哪些计划、每张计划的明细和报工进度。

> ⚠️ 产品下拉是 MES 自己的产品主数据。提示「产品不存在，请先在「基础数据 → 产品」录入产品」，就先回去把产品建出来。

### 第 2 步 · 排进生产计划

**生产计划 → 新建计划**：填 **计划日期**、**挂接订单**（可不挂，那就是独立计划），
在明细里填 **产品 + 数量 + 交期**（可以多条）→ 保存，状态 **草稿**。

然后：

| 动作 | 结果 |
|---|---|
| **确认** | 计划变 **已确认**；若挂了订单且订单还是草稿，订单同步变 **已下达** |
| **追加明细** | 草稿 / 已确认状态下都能加明细 |
| **删除** | **只有草稿能删** |
| **作废** | 计划变 **已作废**；**已完工的计划不能作废**。作废后订单进度会自动重算（作废计划不计入产出） |

### 第 3 步 · 排产派工

两种做法，随便用一种。

**做法 A · 按工艺路线一键生成（推荐）**：在计划明细行上点「按工艺路线自动生成工序任务」。
系统按产品的工艺路线、按 **步骤顺序** 一次性生成全部工序任务（工序、默认机台取自路线，
派工数量 = 明细数量，**工人留空**先进任务池）；计划同时从已确认变 **进行中**。

> 报错「该产品未定义启用的工艺路线或路线无步骤」= 路线没配或没启用；
> 报错「该明细已生成过工序任务（请先删除旧任务再生成）」= 幂等保护，别重复点。

**做法 B · 手工派工**：**排产派工 → 新增派工**：选 **计划明细**、**工序**、**机台/工位**、
**工人**（留空就进任务池，让工人自己领）、**派工数量**、计划开始/结束时间 → 保存。

任务状态按这个顺序走：**待开工** →（开工）**进行中** →（暂停）**已暂停** →（报工满额 或 手动完工）**已完工**。

**设备会挡一道**：如果某个工位下面的设备**全部**不可用（停用 / 维修中 / 已报废），这个工位的
**派工、改派、开工都会被拦**，提示「工位下设备均不可用（…），请先恢复设备状态或改派其他工位」；工位下没挂设备则直接放行。

### 第 4 步 · 报工

**路径 A · 生产报工（班组长 / 统计员用）**：**生产报工 → 提交报工**，选 **任务**，
填 **合格数 / 返工数 / 报废数**、**工时**、**班次**（**留空就按当前时间自动识别**）、**备注** → 提交。

**路径 B · 员工报工（工人自己用）**：**员工报工** 进去是工位模式（大按钮）：

1. **可领取任务** 里挑一个 → **领取**（只有「没指派工人」且「待开工」的任务能领，被别人领了会提示）；
2. **开工** → 干完 **报工**（合格 / 返工 / 报废）→ 要停一下点 **暂停**，回来点 **继续**，结束点 **完工**。

工人身份强制等于登录账号，**不能操作别人的任务**。

**报工提交后系统自动往上推三级**（这是 MES 的核心，不用人工干预）：

1. 该任务累计合格数 ≥ 派工数量 → **任务自动完工**；
2. 明细下任务汇总达标 → **明细完成**；全部明细完成 → **计划完工**；
3. **回写订单**：已产数量累计；订单状态 已下达 → **进行中** → 全部计划完工后变 **已完工**
   （已完工 / 已作废的订单不会被反向推进）。

**分岔：这个工序是不是必检？**

| 工序设置 | 报工后发生什么 |
|---|---|
| **免检**（未勾必检） | 合格数当场计入 → 立刻推进进度，**并当场结算计件工资**，提示「报工成功，计件工资 +X 元」 |
| **必检** | 本次数量全部转成 **待检数**、合格数清零 → **不推进完工**，提示「报工成功，N 件待检验」 |

### 第 5 步 · 质量检验（必检工序才有）

**质量检验 → 待检单**：必检工序报工后，条目会自动出现在这里。点 **判定**：

1. 填 **合格数 / 返工数 / 报废数** —— ⚠️ **三者之和必须等于待检数**，不等会被拦；
2. 有返工或报废时选 **不良代码**（选填，但强烈建议选，后面质量归因要靠它）；
3. 填 **备注** → **提交判定**，提示「检验完成，产量已更新」。

判定之后系统会做两件事：待检数按判定结果拆成合格 / 返工 / 报废，然后**重走一遍第 4 步的联动**
（任务 → 明细 → 计划 → 订单）并**按最终合格数结算计件工资**（返工、报废拿不到钱）；同时往追溯链补一条「生产检验判定」。

**复检**：返工后重新送检、或想把已判定的结果再判一次，判定时勾上 **复检**。
复检按「本次合格数 − 已结算数量」的差额 **补发或冲回**工资，**不会重复发钱**。

> 报错「判定数量之和(x) 必须等于待检数(y)」= 三个数没加对；
> 报错「该报工已完成检验；如需再次判定，请勾选「复检」」= 已经判过了；
> **免检工序的产出不需要检验**，来判定会被拒绝。

### 第 6 步 · 看计件工资

**计件工资** 页三个页签：

| 页签 | 看什么 |
|---|---|
| **结算流水** | 每一条工资记录：工人、班次、工序、计件数量、单价、金额、来源、结算时间。可按工人 / 班次 / 工序 / 日期筛 |
| **汇总** | 按 **工人 / 工序 / 班次** 三个维度汇总，默认当月，也可以选统计区间看 |
| **班次管理** | 新增 / 编辑 / 删除班次（编码、名称、上班时间、下班时间、跨零点、是否启用、排序） |

结算规则再强调一遍：数量取 **合格数**（**返工、报废不计件**）；单价取 **工序** 上的计件单价，
工序没单价或单价 ≤ 0 → **不产生工资流水**（不落 0 元脏数据）；**单价落库即冻结**，之后再改工序单价不会篡改历史工资；
结算时点：免检 = 报工当场，必检 = 检验判定后。

## 四、日常操作速查

| 页面 | 你会在这里做的事 |
|---|---|
| **概览** | 今日计划（完成/总数）、今日合格、今日报废、待派工/待开工/进行中任务数 + 最近订单。车间早会最省事的一屏 |
| **生产订单** | 按 **工单号 / 产品编码 / 产品名称** 搜、按状态筛；看 **进度%** 和关联计划数；点**详情**看订单全景（计划 / 明细 / 报工进度） |
| **生产计划** | 按状态筛；明细上生成工序任务；**只有草稿能删**；**已完工不能作废** |
| **排产派工** | 按工序顺序（sort）排列；行操作 **改派 / 开工 / 暂停 / 手动完工**。只有「待开工 / 已暂停」能开工，「进行中」才能暂停；**手动完工是兜底**，正常靠报工满额自动完工 |
| **生产报工** | 提交报工；按任务、按班次查全部报工记录 |
| **员工报工** | 工位大按钮：我的任务、可领取任务、领取、开工、暂停、继续、完工、报工 |
| **车间看板** | 今日计划（完成/总数）、待派工/待开工/进行中/已完工任务数、今日合格/报废，下面列出 **进行中 / 已暂停** 的任务（产品、工序、派工数、已报数） |
| **质量检验** | **待检单**（必检报工自动进入，可搜计划号/产品/工序）、**检验记录**（含复检标记）、**不良代码**（判定不合格时选） |
| **设备管理** | 只读台账 + **切换生产状态**；**报停**（自动置维修中）/**结束停机**（自动算时长并恢复可用）；停机统计。想让设备从维修中恢复，**必须先结束停机记录** |
| **质量追溯** | 按 **工单 / 产品 / 批次序列号 / 设备** 四维查、事件流水、概览统计 |
| **计件工资** | 结算流水、按工人/工序/班次汇总、班次管理 |
| **基础数据** | 产品 / 工序 / 机台工位 / 物料 / 工艺路线 / BOM / 工人名单（只读） |
| **MES 设置** | 占位页，暂无内容 |

## 五、进阶用法

**概览页**：今日计划（完成/总数）、今日合格、今日报废、待派工 / 待开工 / 进行中任务数 + 「最近订单」清单，车间早会最省事的一屏。

**工艺路线 + BOM（让排产自动化）**：**工艺路线** 定义这个产品走哪几道工序、什么顺序、默认上哪台机台、标准工时多少；
**BOM** 定义这个产品要用哪些物料、单台用量多少。配好路线后，计划明细上点一下就能生成全套工序任务，不用一行行手工派工。

**质量追溯（四种维度还原全链路）**：**质量追溯** 页支持

| 维度 | 怎么用 |
|---|---|
| **按工单** | 选一个可追溯工单，看它的完整时间线 |
| **按产品** | 输入产品编码 → 查看该产品所有追溯事件 |
| **按批次 / 序列号** | 输入批次号或序列号后点查询 —— **这是跨 ERP/MES 串联全链路的入口** |
| **按设备** | 看该设备的停机与恢复流水；**事件流水** 可按事件类型 / 日期筛全部明细 |

事件按业务顺序聚成四段：**来料 / 入库 → 生产制造 → 质量检验 → 出库 / 发货**，
并标出这段是 **MES 记的（制造段）** 还是 **ERP 记的（采购 / 出货段）**。

MES 会在**四个制造节点自动留痕**：**开工、报工、检验判定、设备停机 / 恢复**。
所以「采购收货 → 制造 → 检验 → 销售出货」这条链在追溯页上是连起来的。
如果某个工单显示「说明制造环节还没留痕」，去开工或报工，这一节就补齐了。

## 六、管理员设置

### MES 设置

**MES 设置** 页目前是**占位页，还没有可配项**。MES 的所有配置都分散在业务页里，别的地方找不到东西时对照这张表：

| 想配什么 | 去哪儿配 |
|---|---|
| 产品、工序（含计件单价、是否必检）、机台工位、物料、工艺路线、BOM | **基础数据** |
| 班次 | **计件工资 → 班次管理** |
| 不良代码 | **质量检验 → 不良代码** |
| 设备台账的新增 / 修改 / 删除 | **ERP 的设备管理**（MES 侧只读，仅能切状态） |

### 维护顺序建议（新厂上线）

1. 先在 **基础数据** 建 **产品**、**工序**（记得填计件单价、勾不勾必检）、**机台/工位**、**物料**；
2. 再建 **工艺路线**（绑产品）和 **BOM**（绑产品）；
3. 到 **计件工资 → 班次管理** 建好白班 / 夜班（报工才能自动归班次），到 **质量检验 → 不良代码** 录常见不良；
4. 设备台账先在 **ERP** 里建完，回到 MES 只做状态维护。

## 七、权限对照表

一线工人**只需要一个权限点**就能干活，管理动作才需要额外权限。完整 20 个权限点：

| 权限码 | 能做什么 |
|---|---|
| `mes:order:read` | 看生产订单列表 / 详情（含进度与计划全景） |
| `mes:order:write` | 新建生产订单 |
| `mes:plan:read` | 看计划列表 / 详情；**车间看板**也走这个权限 |
| `mes:plan:write` | 新建 / 删除计划、确认、作废、追加明细 |
| `mes:task:read` | 看派工任务列表 |
| `mes:task:write` | **开工 / 暂停 / 手动完工** |
| `mes:task:dispatch` | **派工 / 改派**、按工艺路线自动生成工序任务 |
| `mes:report:read` | 看报工记录 |
| `mes:report:write` | **提交报工**（生产报工页） |
| `mes:workstation` | **员工报工**工位页全套：看我的任务、可领取任务、领取、开工、暂停、完工、工位报工 |
| `mes:basedata:read` | 看基础数据（工序 / 机台 / 产品 / 物料 / 工艺路线 / BOM / 工人名单） |
| `mes:basedata:write` | 增删改基础数据（含工艺路线、BOM） |
| `mes:quality:read` | 看待检单、检验记录、不良代码、质量统计 |
| `mes:quality:write` | **提交检验判定**、维护不良代码 |
| `mes:wage:read` | 看计件工资流水与汇总、看班次、查当前班次 |
| `mes:wage:write` | 班次的新增 / 修改 / 删除 |
| `mes:equipment:read` | 看设备列表、停机记录、停机统计 |
| `mes:equipment:write` | **切换设备状态**、报停、结束停机、删除停机记录 |
| `mes:trace:read` | 质量追溯全部功能（四维查询、事件流水、概览统计） |
| `mes:admin` | MES 管理级操作 |

> 最省事的分配方式：
> **一线工人** —— 只给 `mes:workstation`
> **班组长 / 调度** —— `mes:task:read/write/dispatch`、`mes:report:read/write`、`mes:plan:read`、`mes:basedata:read`
> **计划员** —— 在上面基础上加 `mes:order:read/write`、`mes:plan:write`
> **质检员** —— `mes:quality:read/write`、`mes:report:read`、`mes:basedata:read`
> **设备员** —— `mes:equipment:read/write`
> **统计 / 财务** —— `mes:wage:read`、`mes:report:read`
> **工艺员** —— `mes:basedata:read/write`

## 八、常见问题

**Q：菜单里看不到「MES 制造执行」或某个子菜单？**
没有权限。菜单按权限显示，找管理员在角色里挂上，**权限实时生效，不用重新登录**。
**Q：新建生产订单报「产品不存在，请先在「基础数据 → 产品」录入产品」？**
订单的产品只能从 MES 自己的产品主数据里选。先去 **基础数据 → 产品** 建好。
**Q：点「按工艺生成工序任务」报「该产品未定义启用的工艺路线或路线无步骤」？**
去 **基础数据 → 工艺路线** 给这个产品配一条**启用**的路线，并且要加步骤（工序 + 顺序）。
**Q：为什么任务派不出去 / 开工报「工位下设备均不可用」？**
这个工位下面的设备全是停用 / 维修中 / 已报废。去 **设备管理** 把设备状态切回 **可用**
（有未结束的停机记录要先 **结束停机**），或者把任务改派到别的工位。
**Q：报工了但任务没完工、计划没推进？**
先看这个工序是不是 **必检**：必检工序报工后数量进了「待检数」，合格数是 0，**必须等检验员判定**才会推进。
去 **质量检验 → 待检单** 判定。
**Q：报工成功了但计件工资没有 / 没有提示金额？**
三个常见原因：① 这个 **工序没填计件单价**（留空或 0 = 不计件）；② 任务 **没挂工序**，无从取单价；
③ 是 **必检工序**，要等检验判定合格后才结算。
**Q：判定时提示「判定数量之和必须等于待检数」？**
填的 合格 + 返工 + 报废 三个数要刚好等于待检数，一个不能多、不能少。
**Q：判过的报工想再判一次？**
判定时勾上 **复检**。复检会按差额补发或冲回工资，不会重复发钱。
**Q：计划删不掉 / 不能确认？**
**只有草稿状态能删**；**没有明细不能确认**（只有草稿能确认）。已完工的计划也不能作废。
**Q：班次删不掉？**
这个班次已经被报工或工资流水引用了。别删，改成 **取消启用** 即可，历史数据不受影响。
**Q：设备在 MES 里加不了？**
设计如此 —— 设备台账是 ERP/MES 共享真表，**新增 / 修改要在 ERP 设备管理里做**，MES 侧只读 + 切状态。

## 附：状态与枚举对照

- **生产订单**：草稿 / 已下达 / 进行中 / 已完工 / 已作废。**生产计划**：草稿 / 已确认 / 进行中 / 已完工 / 已作废；
  **计划明细**：待处理 / 进行中 / 完成；**派工任务**：待开工 / 进行中 / 已暂停 / 已完工。
- **报工检验状态**：免检 / 待检 / 已判定合格 / 不合格；**检验判定结果**：合格 / 返工 / 报废 / 部分合格。
- **设备状态**：可用 / 停用 / 维修中 / 已报废；**停机原因**：设备故障 / 换型调机 / 待料 / 停电 / 保养点检 / 缺人 / 其他。
- **不良严重度**：轻微 / 严重 / 致命。**班次**：如 白班 / 夜班 / 中班，可标记是否跨零点。
- **追溯阶段**：来料 / 入库 → 生产制造 → 质量检验 → 出库 / 发货；MES 写入的事件：开工 / 报工 / 生产检验判定 / 设备停机 / 停机恢复。
