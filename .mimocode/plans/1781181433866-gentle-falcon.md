# 应用中心完整方案

## 一、现状分析

**已有基础：**
- `AppManifest` dataclass（base.py）— 定义 app 元数据
- `app_registry.py` — 扫描 manifest、安装/卸载、权限委派
- `InstalledApp` 模型（platform_apps 表）— 记录安装状态
- CMS app 有完整 manifest（内容类型/字段/分类）
- 前端 `AppsView.vue` — 安装/卸载/详情/权限委派

**缺失：**
1. 安装时不自动注册菜单（menus 字段定义了但没用）
2. 路由全部硬编码在 `api/v1/__init__.py`
3. 没有示范 App
4. 没有应用商店 UI

## 二、完善插件机制

### 2.1 安装时自动注册菜单

**文件：** `apps/system/app_registry.py` `install_app()`

安装时读取 manifest.menus，自动写入 `rbac_menus` 表 + 关联超级管理员角色：

```python
# install_app() 中新增
if manifest.menus:
    from cenkor_admin.apps.rbac import models as rbac_models
    for menu_def in manifest.menus:
        # 递归创建菜单树
        _register_menu_tree(db, menu_def, parent=None, role_id=super_admin_role_id)
```

### 2.2 安装时自动注册权限

**文件：** `apps/system/app_registry.py` `install_app()`

```python
if manifest.permissions_required:
    for perm_code in manifest.permissions_required:
        # 幂等：存在就跳过
        existing = await db.execute(select(Permission).where(Permission.code == perm_code))
        if not existing.scalar_one_or_none():
            db.add(Permission(code=perm_code, type="api", name=perm_code))
```

### 2.3 路由动态注册（方案：约定式路由）

**文件：** `api/v1/__init__.py`

每个 App 的路由文件放在固定位置，安装时通过 import 动态加载：

```python
# 启动时 / 安装时动态加载已安装 App 的路由
async def register_app_routes(app, installed_apps: list[str]):
    for app_key in installed_apps:
        try:
            mod = importlib.import_module(f"cenkor_admin.apps.{app_key}.router")
            if hasattr(mod, "router"):
                app.include_router(mod.router, prefix=f"/api/v1/{app_key}")
        except ImportError:
            pass
```
